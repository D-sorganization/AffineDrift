# Security Policy

## Supported Versions

As this is a static website and research repository, we support the current version deployed to the main branch.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a vulnerability, please report it via the following steps:

1.  **Do not open a public issue.**
2.  Email the repository owner or open a **private** GitHub advisory if enabled.
3.  Include a description of the vulnerability and steps to reproduce.

### Response

- We will acknowledge your report within 48 hours.
- We will provide an estimated timeline for the fix.
- We will notify you when the fix is deployed.

## Scope

This policy applies to:
- The `AffineDrift` website content and scripts.
- The build tools and utilities in this repository.

## Out of Scope

- GitHub Pages infrastructure (please report to GitHub).
- Third-party libraries (please report to the respective maintainers).
