# AffineDrift
Website design for my golf research page.

## Overview
This is a starter website layout for golf biomechanics research content, featuring sections for papers, publication reviews, and future project links.

## Structure
- `index.html` - Main website page with semantic HTML structure
- `styles.css` - Responsive CSS stylesheet with clean, professional design

## Features
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Semantic HTML**: Proper heading hierarchy and semantic elements
- **Accessible Navigation**: Sticky header with clear navigation links
- **Content Sections**:
  - About: Introduction to the research page
  - Papers: Original research and analysis
  - Reviews: Publication reviews and commentary
  - Projects: Links to GitHub repositories (coming soon)
- **Professional Styling**: Clean design with golf-themed green color palette

## Getting Started
1. Open `index.html` in a web browser to view the site
2. Edit the HTML content to add your papers, reviews, and project information
3. Customize colors in `styles.css` by modifying the CSS variables in `:root`
4. Add actual links when you have content ready to publish

## Customization
The color scheme can be easily modified in `styles.css`:
```css
:root {
    --primary-color: #2c5f2d;  /* Main green color */
    --secondary-color: #97be5a; /* Lighter accent green */
}
```
