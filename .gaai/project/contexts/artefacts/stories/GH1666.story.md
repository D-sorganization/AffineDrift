# GH1666: Hessian computation has O(n^3) complexity with nested finite differences

**Source:** D-sorganization/AffineDrift#1666

## Description

## Assessment: E. Performance (score 6/10)

**Finding:** `src/affine_control/residuals.py` `compute_hessian_norm()` computes the Hessian tensor by calling `_finite_diff_jacobian` (which itself loops over state dimensions) inside a loop over state dimensions. For state dimension n, this results in O(n^2) calls to the dynamics function `f`, each of which calls `f` 2n times for the Jacobian, yielding O(n^3) total dynamics evaluations.

For the 6-DOF spacecraft system (n=6), this means 6 * 2*6 = 72 dynamics evaluations per Hessian computation. For the double pendulum (n=4), it is 32 evaluations. Each DDP timestep computes this for every point on the trajectory.

**Impact:** Performance bottleneck for higher-dimensional systems. The current design is acceptable for n<=6 but will not scale.

**Fix:** Document the O(n^3) complexity. For production use, add a note about JAX/CasADi automatic differentiation as mentioned in the docstring. Consider caching Jacobians when the trajectory hasn't changed significantly.

**File:** `src/affine_control/residuals.py:104-141`
