# GH1668: ResidualMonitor never transitions to MPC_WARN state

**Source:** D-sorganization/AffineDrift#1668

## Description

## Assessment: P4. Tracer Bullets / D. Error Handling

**Finding:** `src/affine_control/residuals.py` `ResidualMonitor.update()` defines three modes: `LQR`, `MPC_WARN`, `MPC_FULL`. However, the transition logic (lines 249-253) only ever transitions between `LQR` and `MPC_FULL`:

```python
if self.mode == "LQR":
    if self.high_count >= self.n:
        next_mode = "MPC_FULL"
elif self.mode == "MPC_FULL" and self.low_count >= self.n:
    next_mode = "LQR"
```

The `MPC_WARN` state is declared as valid (line 203) but is unreachable. There is no transition into `MPC_WARN`.

**Impact:** Dead state in the mode machine. The warning threshold `eps_warning` is used to reset `low_count` but never triggers `MPC_WARN` mode.

**Fix:** Either implement `MPC_WARN` as an intermediate state (LQR -> MPC_WARN -> MPC_FULL) or remove it from the valid modes.

**File:** `src/affine_control/residuals.py:203,249-253`
