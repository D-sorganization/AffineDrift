# GH1664: rl_funnel_benchmark.py uses sys.stdout.write for output instead of logging

**Source:** D-sorganization/AffineDrift#1664

## Description

## Assessment: L. Logging (score 7/10)

**Finding:** `src/tools/rl_funnel_benchmark.py` `print_results()` function (line 357-378) uses `sys.stdout.write()` for formatted output. While the module correctly uses `logging` for informational messages, the results output should also use the logging framework or be structured as a return value.

The CI rule "No print() in src/" is technically not violated (it uses `sys.stdout.write`), but the intent is circumvented.

**Impact:** Output cannot be redirected or suppressed through standard logging configuration.

**Fix:** Return a formatted string from `print_results()` and let the caller decide how to output it, or use `logger.info()` for the results.

**File:** `src/tools/rl_funnel_benchmark.py:357-378`
