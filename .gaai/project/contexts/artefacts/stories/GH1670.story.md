# GH1670: rl_funnel_benchmark has no input validation on public functions

**Source:** D-sorganization/AffineDrift#1670

## Description

## Assessment: P8. Design by Contract / K. Data Handling

**Finding:** `src/tools/rl_funnel_benchmark.py` public functions lack the Design-by-Contract validation that the core modules consistently use. None of these functions call `require()`, `check_finite_array()`, or `check_positive()`:
- `double_pendulum_drift()` - no state dimension check
- `double_pendulum_B()` - no state dimension check
- `generate_reference_trajectory()` - no time span validation
- `run_benchmark()` - no validation of controller callable or time parameters
- `run_comparison()` - no validation of perturbation_scale
- `setpoint_lqr_controller()` - no dimension check on x_target
- `trajectory_tracking_lqr()` - no validation of reference trajectory dimensions

This is inconsistent with the strong DbC pattern in `src/affine_control/` and `src/core/`.

**Impact:** Users get opaque numpy errors instead of clear precondition messages.

**Fix:** Add `require()` and `check_finite_array()` preconditions consistent with the rest of the codebase.

**File:** `src/tools/rl_funnel_benchmark.py` (all public functions)
