# GH1671: predict_residual_bound silently truncates when array lengths differ

**Source:** D-sorganization/AffineDrift#1671

## Description

## Assessment: D. Error Handling / P8. Design by Contract

**Finding:** `src/affine_control/residuals.py` `predict_residual_bound()` (lines 144-174) accepts three arrays (`M_traj`, `delta_x_traj`, `dt_traj`) but only validates that `dt_traj` is non-empty. If the arrays have different lengths, the loop silently stops at the shortest one (lines 167-168):

```python
if i >= len(M_traj) or i >= len(delta_x_traj):
    break
```

This defensive coding hides bugs. If the caller passes mismatched arrays, they get a partial (incorrect) result with no warning.

**Impact:** Silent data corruption in residual bound computation.

**Fix:** Add a precondition: `require(len(M_traj) == len(delta_x_traj) == len(dt_traj), "all trajectory arrays must have equal length")`

**File:** `src/affine_control/residuals.py:162-168`
