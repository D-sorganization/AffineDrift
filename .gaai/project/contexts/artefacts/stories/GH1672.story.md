# GH1672: I_gamma hardcoded as 0.5 * I_alpha without physical justification

**Source:** D-sorganization/AffineDrift#1672

## Description

## Assessment: P7. Estimation / P6. Domain Languages

**Finding:** `src/tools/wrist_universal_joint/torque_calculator.py` line 64:
```python
i_gamma = 0.5 * i_alpha
```

The comment says "typically 0.5x for golf clubs" but provides no reference. This is a magic scaling factor that significantly affects the torque distribution model.

**Impact:** The 0.5 ratio is an unjustified approximation. Different club types (drivers vs irons vs putters) have different MOI ratios. This hardcoded value makes the model inaccurate for anything other than a specific club type.

**Fix:**
1. Add a citation or measurement source for the 0.5 factor
2. Make it a configurable parameter with a documented default
3. Consider computing from clubhead geometry if possible

**File:** `src/tools/wrist_universal_joint/torque_calculator.py:64`
