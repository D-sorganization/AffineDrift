# GH1657: DRY: double_pendulum_drift and double_pendulum_B duplicate physics parameters

**Source:** D-sorganization/AffineDrift#1657

## Description

## Assessment: P1. DRY / P7. Magic Numbers

**Finding:** In `src/tools/rl_funnel_benchmark.py`, the magic numbers `m1, m2, L1, L2 = 1.0, 1.0, 0.5, 0.5` are duplicated verbatim on lines 42 and 60 (in `double_pendulum_drift` and `double_pendulum_B`). These should be extracted to module-level constants or a dataclass.

**Impact:** If the benchmark pendulum parameters change, both places must be updated manually.

**Fix:** Extract to named constants (e.g., `PENDULUM_M1`, `PENDULUM_L1`, etc.) or a `@dataclass` at the module level.

**File:** `src/tools/rl_funnel_benchmark.py:42,60`
