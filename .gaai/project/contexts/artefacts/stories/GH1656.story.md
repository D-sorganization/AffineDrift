# GH1656: DRY: SpacecraftRendezvous hardcodes constants instead of using EARTH_MU and ISS_ORBIT_RADIUS_M

**Source:** D-sorganization/AffineDrift#1656

## Description

## Assessment: P1. DRY / P7. Magic Numbers

**Finding:** `src/tangent_models/examples.py` line 106 hardcodes `mu: float = 3.986e14, r_t: float = 6771000.0` as default parameters, while `src/core/constants.py` already defines `EARTH_MU = 3.986e14` and `ISS_ORBIT_RADIUS_M = 6_771_000.0`.

**Impact:** These constants are defined in two places. If orbital parameters are refined, the examples module would drift.

**Fix:** Import and use `EARTH_MU`, `ISS_ORBIT_RADIUS_M`, and `DEFAULT_SPACECRAFT_MASS_KG` from `src.core.constants`.

**File:** `src/tangent_models/examples.py:106`
