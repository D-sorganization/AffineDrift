# GH1673: Control saturation limit hardcoded to [-50, 50] in rl_funnel_benchmark

**Source:** D-sorganization/AffineDrift#1673

## Description

## Assessment: P3. Reversibility / P7. Magic Numbers

**Finding:** `src/tools/rl_funnel_benchmark.py` line 267 hardcodes:
```python
u = np.clip(u, -50, 50)
```

This saturation limit is not configurable and has no justification comment. The value 50 N*m may be appropriate for the double pendulum benchmark but would need to change for different systems.

**Impact:** The hardcoded value makes the benchmark non-portable to other systems.

**Fix:** Make the saturation limit a parameter of `run_benchmark()` or extract to a module-level constant.

**File:** `src/tools/rl_funnel_benchmark.py:267`
