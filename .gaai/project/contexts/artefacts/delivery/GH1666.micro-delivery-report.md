## Change Summary

Added a detailed complexity section to the `compute_hessian_norm` docstring explaining:
- The O(n^3) dynamics evaluation count and why it arises (outer loop n iterations × _finite_diff_jacobian's 2n calls)
- Concrete examples: 72 evaluations for 6-DOF spacecraft (n=6), 32 for double pendulum (n=4)
- Performance note that this is acceptable for n≤6 but does not scale
- Recommended alternatives: JAX `jax.hessian` and CasADi `casadi.hessian` via reverse-mode AD (O(n) passes)
- Jacobian caching opportunity when trajectory changes slowly

No behavioral code changes were made. The fix is purely documentation.
