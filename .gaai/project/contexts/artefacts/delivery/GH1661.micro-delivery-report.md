## Change Summary

The `streamlit_app.py` file contained duplicate definitions of four functions:
- `_plot_torque_figure` (original at line 264, duplicate at line 316 renamed `_create_plot_figure`)
- `_plot_acceleration_figure` (original at line 284, duplicate at line 336)
- `_plot_transmission_figure` (original at line 302, duplicate at line 354)
- `_create_plot_figure` (duplicate at line 316 was shadowing the dispatch version at line 368)

The duplicate definitions (lines 316–365) were incorrect versions with:
- `type: ignore[no-any-return]` on return statements
- `type: ignore[type-arg]` on `np.ndarray` parameters

The root cause of `no-any-return` errors: `@st.cache_resource` on `plot_torque`, `plot_acceleration`, and `plot_transmission_sweep` in `plots.py` causes mypy to treat their return type as `Any`.

Fix applied:
1. Removed all duplicate function definitions (lines 316–365)
2. Added `cast` to `from typing import Any, cast`
3. Wrapped returns of the three helper functions with `cast(Figure, ...)` to suppress `no-any-return` cleanly
4. Used `npt.NDArray[Any]` consistently instead of `np.ndarray` without type args
