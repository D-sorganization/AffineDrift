# GH1670 Execution Plan: Input Validation on rl_funnel_benchmark Public Functions

## High-Level Approach

Follow the established DbC pattern used in `src/affine_control/` and `src/core/`:
- Import `require`, `check_finite_array`, and `check_positive` from `src.core.contracts`
- Add precondition guards at the top of each public function
- Write pytest tests for each validation path (TDD)

No approach evaluation needed — the pattern is fully established in this codebase.

## Implementation Sequence

### Step 1: Add imports to rl_funnel_benchmark.py

Add to imports section:
```python
from src.core.contracts.validators import check_finite_array, check_positive
from src.core.contracts.definitions import require
```

### Step 2: Add validations to each public function

**`double_pendulum_drift(t, x, g)`**
- `require(isinstance(x, np.ndarray) and x.shape == (4,), "x must be shape (4,)", x)`
- `check_finite_array(x, "x")`
- `check_positive(g + 1e-300, "g")` — allow 0 only if sensible; require > 0 for physical gravity

**`double_pendulum_B(x)`**
- `require(isinstance(x, np.ndarray) and x.shape == (4,), "x must be shape (4,)", x)`
- `check_finite_array(x, "x")`

**`generate_reference_trajectory(t_span, dt, x0)`**
- `require(len(t_span) == 2 and t_span[1] > t_span[0], "t_span must be (t0, tf) with tf > t0", t_span)`
- `check_positive(dt, "dt")`
- `require(t_span[0] >= 0.0, "t_span start must be >= 0", t_span[0])`
- If x0 is not None: `require(x0.shape == (4,), ...) + check_finite_array(x0, "x0")`

**`run_benchmark(controller, x0_perturbed, t_span, t_ref, x_ref, name, dt)`**
- `require(callable(controller), "controller must be callable", controller)`
- `require(isinstance(x0_perturbed, np.ndarray) and x0_perturbed.shape == (4,), ..., x0_perturbed)`
- `check_finite_array(x0_perturbed, "x0_perturbed")`
- `require(len(t_span) == 2 and t_span[1] > t_span[0], "t_span must be (t0, tf) with tf > t0", t_span)`
- `check_positive(dt, "dt")`

**`run_comparison(perturbation_scale, t_span, dt, seed)`**
- `check_positive(perturbation_scale, "perturbation_scale")`
- `require(len(t_span) == 2 and t_span[1] > t_span[0], "t_span must be (t0, tf) with tf > t0", t_span)`
- `check_positive(dt, "dt")`

**`setpoint_lqr_controller(x_target, Q_sp, R_sp)`**
- `require(isinstance(x_target, np.ndarray) and x_target.shape == (4,), "x_target must be shape (4,)", x_target)`
- `check_finite_array(x_target, "x_target")`

**`trajectory_tracking_lqr(t_ref, x_ref, Q_tt, R_tt)`**
- `require(isinstance(t_ref, np.ndarray) and t_ref.ndim == 1 and len(t_ref) >= 2, "t_ref must be 1D array with >= 2 elements", t_ref)`
- `require(isinstance(x_ref, np.ndarray) and x_ref.ndim == 2 and x_ref.shape[0] == 4 and x_ref.shape[1] == len(t_ref), "x_ref must be shape (4, len(t_ref))", x_ref)`
- `check_finite_array(t_ref, "t_ref")`
- `check_finite_array(x_ref, "x_ref")`

### Step 3: Write tests (new test class in test_rl_funnel_benchmark.py)

One test class `TestInputValidation` with sub-methods testing each invalid input raises `ContractViolationError` (or its subclass `PreconditionError`).

### Step 4: Run checks

```bash
python3 -m ruff check src/tools/rl_funnel_benchmark.py
python3 -m black --check --line-length 100 src/tools/rl_funnel_benchmark.py
python3 -m pytest tests/tools/test_rl_funnel_benchmark.py -v
```

## Edge Cases

- `double_pendulum_drift` called with wrong-length state → clear error
- `generate_reference_trajectory` with t_span reversed (tf < t0) → clear error
- `run_benchmark` with non-callable controller → clear error
- `run_comparison` with negative perturbation_scale → clear error
- `setpoint_lqr_controller` with NaN in x_target → clear error
- `trajectory_tracking_lqr` with mismatched x_ref columns → clear error
