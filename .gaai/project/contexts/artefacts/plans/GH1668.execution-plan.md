# GH1668 Execution Plan

## Story
ResidualMonitor never transitions to MPC_WARN state.

## Approach
Tier 1 (MicroDelivery). Bug is localized to `ResidualMonitor.update()` in one file.

## Fix Design
Implement MPC_WARN as a genuine intermediate state in the mode machine:
- Escalation: LQR -> MPC_WARN -> MPC_FULL (each requiring n_hysteresis critical samples)
- Recovery:   MPC_FULL -> MPC_WARN -> LQR (each requiring n_hysteresis low samples)
- On each LQR->MPC_WARN or MPC_WARN->MPC_FULL transition, reset `high_count` to 0
- On each MPC_FULL->MPC_WARN or MPC_WARN->LQR transition, reset `low_count` to 0

## Files
- `src/affine_control/residuals.py` — fix transition logic in `update()`
- `tests/test_affine_control/test_residuals.py` — update tests to reflect three-state machine
- `tests/test_dbc_application_contracts.py` — update parametrized test expecting old LQR->MPC_FULL direct
- `tests/test_tangent_integration.py` — update integration tests expecting old direct transition
