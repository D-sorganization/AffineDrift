# GH1654 Execution Plan: CI Black runs without --line-length 100, mismatches pyproject.toml

**Tier 1 — MicroDelivery**
- Complexity: 2 (config-only changes, no logic)
- Files affected: 1 (`.github/workflows/ci-standard.yml`)

## Problem Summary

CI `quality-gate` job installs pinned tool versions that differ from `requirements.txt`:
- `black==26.1.0` (CI) vs `black==26.3.1` (requirements.txt)
- `ruff==0.14.10` (CI) vs `ruff==0.15.6` (requirements.txt)
- `mypy==1.13.0` (CI) vs `mypy==1.19.1` (requirements.txt)

Additionally, `black --check .` runs without `--line-length 100` (implicit via pyproject.toml, but fragile).
