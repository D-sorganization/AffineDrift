# GH1607: Execution Plan — Repair deploy and E2E pipeline around generated docs assets

## Summary

Two CI workflow files need targeted fixes to align with the repo's documented build model:
`docs/` content is generated by Quarto at render time and is never committed.

---

## Implementation Sequence

### Step 1 — Fix `deploy-website.yml`: Move asset-sync check after Quarto render

**File:** `.github/workflows/deploy-website.yml`

**Problem:** The `Verify frontend asset sync` step runs BEFORE `Render Website`. Since `docs/css/`
and `docs/js/` are populated by `quarto render`, the `--check` flag reports all mirrors as MISSING.

**Fix:** Move the `Verify frontend asset sync` step to immediately AFTER the `Render Website` step.
At that point `docs/` is populated and the mirrors will exist.

**Edge cases:**
- If a canonical file (e.g., `css/startup-launcher.css`) was modified without updating the mirror,
  the sync check will detect genuine drift and fail correctly — this is the intended behavior.
- No change to the check logic itself; only step ordering changes.

**Test checkpoint:** After render, `docs/css/` and `docs/js/` will exist with correct content.
The `--check` will pass when sources and mirrors are in sync.

### Step 2 — Fix `ci-standard.yml` E2E job: Build site before running tests

**File:** `.github/workflows/ci-standard.yml`

**Problem:** The E2E job skips all browser tests when `docs/index.html` is absent. Since `docs/` HTML
is never committed, E2E tests are effectively never exercised in PR validation.

**Fix:**
1. Add Quarto setup step (`quarto-dev/quarto-actions/setup@v2`) to the E2E job.
2. Add a `quarto render` step (using `quarto-dev/quarto-actions/render@v2`) before the Playwright
   test step.
3. Replace the conditional `if [ -f "docs/index.html" ]` guard with an unconditional Playwright
   invocation — the render step guarantees the artifact exists.
4. Add Python dependency installation before quarto render (needed by `_quarto.yml` Python cells).

**Edge cases:**
- Quarto render in E2E job may fail if Python deps are missing → add `pip install -r requirements.txt`
  before render.
- Render timeout: E2E job already has `timeout-minutes: 8` — increase to 20 to accommodate render.
- `.env.example` issue: add `rm -f .env.example` before render (same pattern as deploy-website.yml).

**Test checkpoint:** E2E smoke tests run and pass after Playwright runs against the generated site.

|------|-----------|------------|
