# GH1667: Execution Plan

## Story
Replace hardcoded indices (250, 200, 300) in `generate_sample_torque` with relative computations based on `len(t)`.

## Tier
Tier 1 — MicroDelivery (1 file affected, complexity ≤ 2, 5 ACs)

## Approach
Direct fix in `src/tools/wrist_universal_joint/torque_calculator.py`:
1. Compute `n = len(t)` once at the top of the dispatch block.
2. Replace each hardcoded index with a relative expression:
   - Step: `torque[250:]` → `torque[n // 2:]`
   - Pulse: `pulse_start = 200`, `pulse_end = 300` → `int(0.4 * n)`, `int(0.6 * n)`
   - Burst: `burst_center = 250`, `burst_width = 50` → `n // 2`, `max(1, n // 10)`
3. Add regression tests in `tests/tools/test_torque_calculator.py` that verify relative behavior at n=100, 200, 1000.
