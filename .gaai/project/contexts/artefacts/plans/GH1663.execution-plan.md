# GH1663 Execution Plan

## Story
RobotArm.linearize uses forward-difference instead of central-difference like other Hessian code.

## Tier
Tier 1 — MicroDelivery (complexity ≤ 2, 2 files affected, clear fix)

## Approach
Switch `RobotArm.linearize()` in `src/tangent_models/examples.py` from forward finite differences
`(f_pert - f0) / epsilon` to central finite differences `(f_plus - f_minus) / (2 * epsilon)`,
matching the pattern in `_finite_diff_jacobian` in `src/affine_control/residuals.py`.

## Files to Change
1. `src/tangent_models/examples.py` — change `linearize()` method in `RobotArm` class
2. `tests/test_tangent_examples.py` — add test verifying central-difference accuracy

## Acceptance Criteria Mapping
- AC1: Forward-difference replaced with central-difference in RobotArm.linearize
- AC2: New test verifying accuracy of central-difference implementation
- AC3: ruff check passes on modified files
- AC4: No new print() calls added
- AC5: PR created targeting staging
