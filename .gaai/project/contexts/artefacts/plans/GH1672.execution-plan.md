# GH1672 Execution Plan

## Summary

Replace the hardcoded `0.5` magic constant in `calculate_moments_of_inertia()` with a
configurable `i_gamma_ratio` parameter (default `0.5`), document its physical basis,
and add tests for the new parameter.

## Files to Modify

| File | Action |
|------|--------|
| `src/tools/wrist_universal_joint/torque_calculator.py` | Add `i_gamma_ratio` parameter, validate, update docstring |
| `tests/tools/test_torque_calculator.py` | Update existing test, add 2 new tests |

## Implementation Steps

### Step 1 — Modify `calculate_moments_of_inertia()`

File: `src/tools/wrist_universal_joint/torque_calculator.py`

- Add `i_gamma_ratio: float = 0.5` as the last positional parameter with default value
- Call `check_positive(i_gamma_ratio, "i_gamma_ratio")` after the existing checks
- Replace `i_gamma = 0.5 * i_alpha` with `i_gamma = i_gamma_ratio * i_alpha`
- Extend docstring:
  - Add `i_gamma_ratio` under Args with description:
    `Ratio of I_gamma to I_alpha. Defaults to 0.5, a typical value for golf clubs
    (ref: Jorgensen, T. (1994) *The Physics of Golf*, AIP Press). Different club types
    (drivers vs irons vs putters) may have different ratios.`
  - Update Returns to reflect that I_gamma now depends on this ratio

### Step 2 — Update tests

File: `tests/tools/test_torque_calculator.py`

- Update `test_i_gamma_is_half_i_alpha`:
  - Rename to `test_i_gamma_default_ratio`
  - Call with explicit `i_gamma_ratio=0.5`; assert `i_gamma == pytest.approx(0.5 * i_alpha)`
  - Also assert the ratio holds for the default (call without keyword too)

- Add `test_i_gamma_custom_ratio`:
  - Call with `i_gamma_ratio=0.3`
  - Assert `i_gamma == pytest.approx(0.3 * i_alpha)`

- Add `test_raises_on_non_positive_i_gamma_ratio`:
  - Call with `i_gamma_ratio=0.0`
  - Assert raises `AssertionError`

## Edge Cases

| Case | Expected behaviour |
|------|--------------------|
| `i_gamma_ratio=0.0` | `check_positive` raises `AssertionError` |
| `i_gamma_ratio<0` | `check_positive` raises `AssertionError` |
| `i_gamma_ratio=2.0` | Allowed; `i_gamma > i_alpha`; `ensure(i_gamma > 0)` still passes |
| Default call (no `i_gamma_ratio`) | Behaves identically to old code |
