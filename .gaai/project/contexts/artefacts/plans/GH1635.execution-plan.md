# GH1635: Execution Plan — Refactor 26 Functions Exceeding 50-Line Threshold

## Story Summary

Refactor functions exceeding the 50-line threshold by extracting cohesive sub-functions.
Top offenders: optimize() 130L, plot_transmission_sweep 93L, analyze_matlab_file 76L.

## Complexity Assessment

- **Tier:** 2 (Core Team)
- **Complexity score:** 5
- **Files affected:** 9 source files + corresponding test files
- **Approach evaluation:** Not triggered — extract-sub-function is an established pattern

## Approach Rationale

Standard extract-function refactoring: identify cohesive logical blocks within each long
function, extract to named private helper with a clear docstring, update the caller to
delegate to the new helper. All public APIs remain unchanged (no rename, no signature
change). New private helpers get tests where independently testable.

## Edge Cases

- `@st.cache_resource` decorators: extracted private helpers must NOT carry the decorator;
  only the public cached function is decorated. Extracted helpers are called from within
  the cached function's body.
- Module-level constants (ACCEPTABLE_NUMBERS, KNOWN_CONSTANTS): must be defined before
  the functions that reference them; no circular imports.
- Extracted functions used only internally: name with `_` prefix.
- All extracted functions must have docstrings (CI enforces this).

## Test Checkpoints

1. After each step: `python3 -m pytest tests/ -x -q` — zero regressions
2. After all steps: `python3 -m ruff check src/` — zero violations
3. After all steps: `python3 -m black --check --line-length 100 src/` — zero diffs
4. Final: `python3 -m pytest --cov --cov-fail-under=50` — coverage still >= 50%

## Risk Register

| Risk | Likelihood | Mitigation |
|------|-----------|------------|
| `@st.cache_resource` applied to helper causes duplicate cache | Low | Only decorate the public wrapper |
| Extracted helper changes closure semantics (e.g. `x_traj` var in loop) | Medium | Pass required state explicitly as args |
| Ruff flags extracted function as dead code | Low | Functions are called; ruff checks callers |
