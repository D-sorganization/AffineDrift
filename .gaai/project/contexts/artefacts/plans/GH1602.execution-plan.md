## Edge Cases

- `create_html_page` with empty template_content → returns False immediately
- `process_file_content` with file not found → returns False
- `find_html_files` when docs/ doesn't exist → returns []
- `check_ast_issues` with syntax error in content → returns error tuple
- `MATLABQualityChecker.run_all_checks` with no matlab dir → skips gracefully

## Test Checkpoints

After each step, run `python3 -m pytest --cov=src --cov-report=term --cov-fail-under=50 -q tests/<file>` to verify local increases. Full coverage check after all steps.
