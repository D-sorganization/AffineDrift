# GH1654 Memory Delta

## Pattern: CI Tool Version Alignment

**Context:** CI quality gates that install pinned tool versions separately from `requirements.txt` can silently diverge, causing format/lint disagreements between local dev and CI.

**Convention established:** CI `pip install` lines for lint/format tools (black, ruff, mypy) should match versions in `requirements.txt`. When a CI job uses explicit version pins, update both files in the same commit.

**Key files:**
- `.github/workflows/ci-standard.yml` — the quality gate install step
- `requirements.txt` — the source of truth for tool versions

**Note:** Black reads line-length from `pyproject.toml` by default, but explicit `--line-length 100` in CI is preferred for self-documenting clarity.
