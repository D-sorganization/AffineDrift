# GH1699 Memory Delta

## Pattern: Budget-check self-detection via obfuscation

When adding markers to a budget-check script, use concatenation to prevent
the script from counting its own definition lines:

```python
# Correct: obfuscated, won't self-detect
_TODO = "TO" + "DO"
MARKERS = (..., _TODO, ...)
```

Test files that verify these markers must also use obfuscated references
in both assertions AND docstrings to avoid false-positive counts.

## Decision: .github/ excluded from tech-debt budget scan

Workflow YAML files legitimately reference TODO/FIXME/XXX as grep patterns
in CI scan steps. Including `.github/` in the budget scan scope creates
false positives. Excluded as of GH1699.

## Config/script contract

`config/tech_debt_budget.json` defines the authoritative list of marker
types and their budgets. `scripts/check_tech_debt_budget.py` must enforce
all markers listed in `max_per_marker`. If new marker types are added to
the config, the script must be updated to match.
