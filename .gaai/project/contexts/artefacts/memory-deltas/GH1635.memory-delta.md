# GH1635 Memory Delta

## Pattern: Extract-to-Private-Helper for >50L Functions

**What worked well:**

1. **Module-level constant extraction** (line_checks.py) — moving `acceptable_numbers` set and
   `known_constants` dict from inside the function to module-level frozenset/dict constants
   reduces line count without moving logic and enables independent testing of the data.

2. **Closed-over state passed as explicit args** — `_run_optimization_loop` in swing_optimizer
   demonstrates the pattern: pass all required context as parameters rather than closing over
   `self` state, enabling isolated unit testing of the loop body.

3. **`@st.cache_resource` on public wrapper only** — private computation helpers must NOT carry
   the Streamlit cache decorator. Only the public cached function keeps the decorator.

4. **Ruff I001 auto-fix** — when adding module-level definitions before imports, ruff --fix
   corrects import ordering automatically. Include this in the workflow.

## No Architectural Decisions

All changes are within-file extractions. No new modules, no new dependencies, no API changes.
