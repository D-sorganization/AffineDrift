# Memory Delta — GH1665

## Pattern: Vacuous len >= 0 vs isinstance for list type checking

When writing DbC checks for dataclass fields with `list` type annotations, use
`isinstance(x, list)` rather than `len(x) >= 0`. The latter is always True and
provides no validation — it only verifies the object has a `__len__` method.

**Use `isinstance(x, list)` when:** the intent is type enforcement (field should be a list).
**Use `len(x) > 0` when:** the intent is non-empty enforcement (field must not be empty).

This distinction matters in `require()` contracts throughout `src/affine_control/`.
