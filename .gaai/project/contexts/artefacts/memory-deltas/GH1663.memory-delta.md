# GH1663 Memory Delta

## Pattern: Consistent Finite-Difference Scheme

**Domain:** Numerical methods / tangent models

**Finding:** The codebase has a canonical central-difference utility `_finite_diff_jacobian` in
`src/affine_control/residuals.py`. Any new linearization code in `src/tangent_models/` should
use central differences `(f_plus - f_minus) / (2 * eps)` to match this convention and achieve
O(eps^2) accuracy.

**Recommendation:** When implementing numerical Jacobian computations, either reuse
`_finite_diff_jacobian` directly or apply the same central-difference formula inline.
Forward differences should be avoided for consistency and accuracy.

**Files involved:**
- `src/affine_control/residuals.py` (canonical utility)
- `src/tangent_models/examples.py` (now consistent)
