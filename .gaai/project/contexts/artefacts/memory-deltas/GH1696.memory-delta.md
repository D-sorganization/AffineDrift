# GH1696 Memory Delta

## New Patterns

### AST-based print() detection

When checking for disallowed `print()` calls in Python source, use `ast.parse`
rather than regex/grep. String literals like `"print("` are common in
code-analysis tools and would produce false positives with text search.

Pattern:
```python
for node in ast.walk(tree):
    if isinstance(node, ast.Expr) and isinstance(node.value, ast.Call):
        if isinstance(node.value.func, ast.Name) and node.value.func.id == "print":
            # genuine print() call
```

### CI check script pattern

All enforcement scripts follow:
1. `_collect_<scope>_files(repo_root)` — returns filtered file list
2. `check_file(path)` — returns list of violation strings
3. `main()` — uses `budget_check_utils.report_results` for consistent output/exit
