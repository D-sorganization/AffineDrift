# GH1668 Memory Delta

## Pattern: Three-State Mode Machine Counter Reset on Transition

When implementing multi-stage hysteresis state machines, reset the triggering counter when transitioning between states. This prevents the next transition from triggering immediately on accumulated counts from the previous stage.

### Applied In
`ResidualMonitor.update()` — `high_count` reset on LQR->MPC_WARN and MPC_WARN->MPC_FULL; `low_count` reset on MPC_FULL->MPC_WARN and MPC_WARN->LQR.

## Pattern: Update Tests When Fixing Dead States
Tests written against buggy code that encoded the wrong behavior (e.g., LQR->MPC_FULL directly) must be updated as part of the fix. These are not regressions — they were testing the wrong thing.
