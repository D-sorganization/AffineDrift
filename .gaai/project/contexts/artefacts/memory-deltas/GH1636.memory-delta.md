# Memory Delta: Docstring Coverage Ratchet Pattern

## Pattern

When delivering a story to improve docstring coverage, add a pytest ratchet test
(`tests/test_docstring_coverage.py`) that enforces a numeric threshold (e.g. 95%).
This prevents future regressions without needing a separate CI gate.

## Key Insight

Prior delivery work had already raised docstring coverage to ~98.5%. The story's
stated baseline of 33% was from an earlier assessment. The implementation correctly
focused on remaining gaps (empty `__init__.py` module docstrings and one missing
class docstring) rather than re-doing already-complete work.

## Convention

- Module docstrings: 1-3 sentence description of what the module provides.
- Empty `__init__.py` files should get a minimal module docstring, not stay empty.
- `@dataclass` classes need a class body docstring describing fields via Attributes section.
