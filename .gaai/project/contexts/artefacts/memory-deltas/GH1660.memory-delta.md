# GH1660 Memory Delta

## Pattern: Helper Extraction for Function Size Compliance

When refactoring functions that exceed the 50-line threshold, extracting
helper functions within the same module increases the module's total line count.
To meet both function-size AND file-size thresholds simultaneously, module
splitting into separate files is required.

**Guideline:** When a file exceeds 400 lines AND all functions exceed 50 lines
via helper extraction alone, escalate to Discovery for module split planning
before delivery.

## Pattern: Streamlit Module-Level Import

`streamlit_app.py` executes full app logic at module-level import, making
individual function testing impractical without extensive mocking. Tests for
helpers in such modules should be integration-tested via the full application
flow, not unit-tested in isolation.

## Coverage Observation

The refactored codebase maintained 95.65% coverage throughout — helper extraction
without architectural changes preserves coverage since the same code paths are exercised.
