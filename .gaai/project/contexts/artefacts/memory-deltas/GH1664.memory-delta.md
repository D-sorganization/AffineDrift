# GH1664 Memory Delta

## Pattern

When converting `sys.stdout.write()` to `logger.info()`, existing tests using `capsys` must
be migrated to `caplog` with `caplog.at_level(logging.INFO, logger="<module_name>")` context
manager. Assertions change from `captured.out` to `" ".join(caplog.messages)`.

## Applicability

Any future refactor of output functions in `src/` that uses this same pattern.
