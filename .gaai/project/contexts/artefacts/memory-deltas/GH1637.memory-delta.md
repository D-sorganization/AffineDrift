# GH1637 Memory Delta

## Patterns Worth Persisting

### Test Isolation: Streamlit + Matplotlib Mock Pattern

The `test_wrist_universal_joint_visual.py` file establishes a robust pattern for
testing streamlit-dependent modules without a real streamlit installation:

- Patch `sys.modules["streamlit"]` before importing the module under test
- Use `matplotlib.use("Agg")` to prevent display calls
- Build a fake streamlit module with MagicMock stubs for all UI functions
- Use `@st.cache_resource` mock that passes through functions (no-op decorator)

This pattern should be reused for any future streamlit tool modules.

### tkinter GUI Paths: Untestable in CI

`prompt_for_files()` in `latex_to_quarto.py` uses tkinter file dialogs.
These are not testable in headless CI environments. Accept 78% coverage on
files with GUI fallback paths — document this as expected.
