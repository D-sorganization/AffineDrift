# GH1667: Memory Delta

## Pattern: Relative Index Computation for Signal Generation

When a signal generation function accepts a variable-length array but uses hardcoded indices internally, replace all hardcoded positions with expressions relative to `len(array)`. Common idioms:

- Midpoint: `n // 2`
- Fraction of length: `int(fraction * n)`
- Windowed region: `max(1, n // divisor)` for the half-width

This pattern applies to any function in `src/tools/` that slices into a time or sample array at hardcoded positions.

## Domain
`src/tools/wrist_universal_joint/torque_calculator.py` — `generate_sample_torque()`
