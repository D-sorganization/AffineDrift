## Notable Patterns

### Pattern: Budget Check Utility DRY Consolidation

When adding new shared logic to budget-check CI scripts, the canonical location is
`src/tools/utils/budget_check_utils.py`. Both `check_module_size_budget.py` and
`check_changed_file_size_budget.py` import from this module.

The `resolve_line_limit()` function now centralizes file-limit resolution logic.

explicit_limits, or tiered limits), change it once in `budget_check_utils.py`.
