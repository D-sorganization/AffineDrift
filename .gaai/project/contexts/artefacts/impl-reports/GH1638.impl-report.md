## Rules Applied

- Import ordering: `import logging` placed in stdlib block; `logger = logging.getLogger(__name__)` placed AFTER all imports (including third-party and local)
- Library convention: `__init__.py` files use `logging.NullHandler()` where they have no active logging calls
- Black 100-char: all files formatted, no changes needed
- Ruff E402: fixed by ensuring `logger = ...` assignment is placed after all import statements

## Known Risks / Limitations

- The `logger` objects are defined but no log calls are added to these files; this is intentional. The story asks only that logging infrastructure is present (import + logger), not that it is actively used.
- `wrist_universal_joint/streamlit_app.py` imports streamlit at module level which is an environment constraint (requires streamlit installed).
