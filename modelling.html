Mathematical Modelling

Computational models and simulations of the golf swing

Two-Hand Golf Swing Model

A comprehensive MATLAB implementation of a two-hand golf swing model based on affine control theory. This model implements the theoretical framework developed in our research, allowing for simulation and analysis of golf swing dynamics.

Features:

  • Control-affine system formulation
  • Drift-input force decomposition
  • Flexible shaft modeling
  • Trajectory optimization capabilities
  • Visualization tools for swing analysis
View Model on MATLAB File Exchange →

Model Documentation

The two-hand golf swing model implements the theoretical framework presented in "The Affine Nature of the Golf Swing." The model allows researchers and practitioners to:

  • Simulate golf swing dynamics under various conditions
  • Analyze the contribution of drift vs. input forces
  • Explore optimal control strategies
  • Validate theoretical predictions against experimental data

Usage Instructions

To use the model, download it from the MATLAB File Exchange link above. The model requires MATLAB with the following toolboxes:

  • MATLAB R2020b or later
  • Control System Toolbox
  • Optimization Toolbox (for trajectory optimization)

Detailed documentation and examples are included in the model package.

MuJoCo GUI Model

An interactive MuJoCo-based graphical user interface for exploring golf swing dynamics. This GUI model provides an intuitive interface for users to interact with the golf swing model, visualize dynamics, and understand the system behavior through real-time simulation.

Features:

  • Interactive 3D visualization of the golf swing
  • Real-time parameter adjustment
  • Visual feedback on force decomposition
  • Trajectory playback and analysis
  • User-friendly interface for model exploration

Repository: The MuJoCo GUI model is available on GitHub and serves as an interface to guide users of the model. This tool makes the golf swing model more accessible to researchers, coaches, and enthusiasts who want to explore the dynamics without deep technical knowledge.

GitHub repository link will be added once the model is shared publicly.
