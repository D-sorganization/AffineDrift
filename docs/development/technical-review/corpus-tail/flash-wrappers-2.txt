#### 3. Overstated Claim on Exact Linear Time-Varying Dynamics for Variations on Manifolds
- **File**: `articles/The_Geometry_of_Motion/quarto/volume1.qmd`
- **Text**: *"By formulating variational equations in moving frames, first-order perturbations obey exact linear time-varying dynamics."*
- **Issue**: **[Proven Error / Inconsistent Model Assumptions]** Variational perturbation equations along a reference trajectory represent a first-order Taylor/Lie linearization of the nonlinear flow. Perturbation dynamics are an exact linear system only in the infinitesimal limit ($T_x M$ / tangent bundle); for finite perturbations $\delta x$ on a curved configuration manifold $M$, the true dynamics include higher-order geometric terms (e.g., Riemann curvature tensors or higher-order Lie brackets depending on connection/coordinate choice). Saying perturbations obey "exact linear time-varying dynamics" is misleading unless explicitly qualified as *infinitesimal* variations or defined via the linear variational operator.
- **Correction**: Change to *"first-order infinitesimal variations obey exact linear time-varying (LTV) variational equations"* or *"first-order perturbation approximations obey linear time-varying dynamics."*
