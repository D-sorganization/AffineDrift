#### 1. Instantaneous Screw Axis Formulation

**Equations Evaluated:**
- Spatial velocity field:
  $$\dot{\bm x} = \bm v_s + \bm\omega \times \bm x, \qquad \bm v_s = \dot{\bm p} - \bm\omega \times \bm p$$
- Screw parameters:
  $$\hat{\bm s} = \frac{\bm\omega}{\|\bm\omega\|}, \qquad h = \frac{\bm\omega \cdot \bm v_s}{\|\bm\omega\|^2}, \qquad \bm q = \frac{\bm\omega \times \bm v_s}{\|\bm\omega\|^2}$$

**Independent Verification:**
1. **Consistency of $\bm v_s$**:
   Since $\bm x(t) = R(t)\bm X + \bm p(t)$, differentiating gives:
   $$\dot{\bm x} = \dot R \bm X + \dot{\bm p} = \dot R R^T(\bm x - \bm p) + \dot{\bm p} = [\bm\omega]_\times(\bm x - \bm p) + \dot{\bm p} = (\dot{\bm p} - \bm\omega \times \bm p) + \bm\omega \times \bm x.$$
   This uniquely fixes $\bm v_s = \dot{\bm p} - \bm\omega \times \bm p$, which is the velocity of a fictitious material point instantaneously coincident with the reference frame origin ($\bm x = \bm 0$).
2. **Velocity on the Axis Line**:
   Evaluate the velocity field at $\bm x = \bm q + \lambda \hat{\bm s}$:
   $$\bm v(\bm q + \lambda \hat{\bm s}) = \bm v_s + \bm\omega \times \left(\frac{\bm\omega \times \bm v_s}{\|\bm\omega\|^2} + \lambda \hat{\bm s}\right).$$
   Using the BAC-CAB vector triple product identity $\bm\omega \times (\bm\omega \times \bm v_s) = (\bm\omega \cdot \bm v_s)\bm\omega - \|\bm\omega\|^2 \bm v_s$:
   $$\bm v(\bm q + \lambda \hat{\bm s}) = \bm v_s + \frac{(\bm\omega \cdot \bm v_s)\bm\omega - \|\bm\omega\|^2 \bm v_s}{\|\bm\omega\|^2} + \bm 0 = \frac{\bm\omega \cdot \bm v_s}{\|\bm\omega\|^2}\bm\omega = h \bm\omega.$$
   The velocity field is strictly collinear with $\hat{\bm s}$ with magnitude $h \|\bm\omega\|$.
3. **Nearest Point Condition**:
   $$\bm q \cdot \bm\omega = \frac{(\bm\omega \times \bm v_s) \cdot \bm\omega}{\|\bm\omega\|^2} = 0.$$
   Thus $\bm q$ is the unique point on the axis line closest to the reference origin $\bm 0$.
4. **Dimensions/Units**:
   - $[\bm\omega] = \text{rad/s}$ ($s^{-1}$)
   - $[\bm v_s] = \text{m/s}$
   - $[\hat{\bm s}] = 1$ (dimensionless)
   - $[h] = \frac{(\text{rad/s})(\text{m/s})}{(\text{rad/s})^2} = \text{m/rad}$
   - $[\bm q] = \frac{(\text{rad/s})(\text{m/s})}{(\text{rad/s})^2} = \text{m}$.
   All units are strictly consistent.

#### 4. Ligament Force, Length and Stiffness

**Constitutive Model:**
$$F(\varepsilon) = \begin{cases} 
0, & \varepsilon \le 0 \\
\frac{k\varepsilon^2}{4\varepsilon_1}, & 0 < \varepsilon \le 2\varepsilon_1 \\
k(\varepsilon - \varepsilon_1), & \varepsilon > 2\varepsilon_1
\end{cases}$$

**Continuity Check ($C^1$ smoothness):**
- At $\varepsilon = 0$:
  - $F(0^-) = 0$, $F(0^+) = 0$. Continuous ($C^0$).
  - $\frac{dF}{d\varepsilon}(0^-) = 0$, $\frac{dF}{d\varepsilon}(0^+) = \left.\frac{2k\varepsilon}{4\varepsilon_1}\right|_{\varepsilon=0} = 0$. Continuous ($C^1$).
- At $\varepsilon = 2\varepsilon_1$:
  - Left limit: $F(2\varepsilon_1^-) = \frac{k(2\varepsilon_1)^2}{4\varepsilon_1} = k\varepsilon_1$.
  - Right limit: $F(2\varepsilon_1^+) = k(2\varepsilon_1 - \varepsilon_1) = k\varepsilon_1$. Continuous ($C^0$).
  - Left slope: $\frac{dF}{d\varepsilon}(2\varepsilon_1^-) = \frac{2k(2\varepsilon_1)}{4\varepsilon_1} = k$.
  - Right slope: $\frac{dF}{d\varepsilon}(2\varepsilon_1^+) = k$. Continuous ($C^1$).

**Numerical Worked Example:**
Given parameters: $k = 1000\text{ N}$, $\varepsilon_1 = 0.03$, $\ell_0 = 0.10\text{ m}$.
Note transition point: $2\varepsilon_1 = 0.06$.

1. $\varepsilon = 0.03 \in (0, 0.06]$:
   - $F = \frac{1000 \times (0.03)^2}{4 \times 0.03} = \frac{1000 \times 0.03}{4} = 7.5\text{ N}$.
   - $\frac{dF}{d\varepsilon} = \frac{1000 \times 0.03}{2 \times 0.03} = 500\text{ N}$.
   - Length tangent: $\frac{dF}{d\ell} = \frac{1}{\ell_0}\frac{dF}{d\varepsilon} = \frac{500}{0.10} = 5000\text{ N/m}$.
2. $\varepsilon = 0.06 = 2\varepsilon_1$:
   - $F = 1000 \times 0.03 = 30\text{ N}$.
   - $\frac{dF}{d\varepsilon} = 1000\text{ N}$.
   - Length tangent: $\frac{dF}{d\ell} = \frac{1000}{0.10} = 10000\text{ N/m}$.
3. $\varepsilon = 0.09 > 2\varepsilon_1$:
   - $F = 1000 \times (0.09 - 0.03) = 1000 \times 0.06 = 60\text{ N}$.
   - $\frac{dF}{d\varepsilon} = 1000\text{ N}$.
   - Length tangent: $\frac{dF}{d\ell} = \frac{1000}{0.10} = 10000\text{ N/m}$.

All six values ($7.5\text{ N}, 30\text{ N}, 60\text{ N}$ and $5000\text{ N/m}, 10000\text{ N/m}, 10000\text{ N/m}$) match the text exactly.

**Restoring Tangent (Generalized Stiffness):**
Given $r = -d\ell/dq$, generalized force $Q = r F$.
$$-\frac{dQ}{dq} = -\frac{d}{dq}(r F) = -\frac{dr}{dq} F - r \frac{dF}{dq} = -F \frac{dr}{dq} - r \left(\frac{dF}{d\ell} \frac{d\ell}{dq}\right) = -F \frac{dr}{dq} - r \left(\frac{dF}{d\ell} (-r)\right) = r^2 \frac{dF}{d\ell} - F \frac{dr}{dq}.$$
The expression $r^2 \frac{dF}{d\ell} - F \frac{dr}{dq}$ matches the text identically. Both material stiffness ($r^2 dF/d\ell > 0$) and geometric stiffness ($-F dr/dq = F d^2\ell/dq^2$) are represented with exact signs.

#### 5. Local Model of Spinal Compliance

**Equations & Units:**
$$\Delta W = -K \delta, \qquad K = \begin{pmatrix} K_{uu} & K_{u\phi} \\ K_{\phi u} & K_{\phi\phi} \end{pmatrix}$$
- $\delta = (\bm u, \bm\phi)$: $\bm u$ in $\text{m}$, $\bm\phi$ in $\text{rad}$.
- $W = (\bm f, \bm m)$: $\bm f$ in $\text{N}$, $\bm m$ in $\text{N}\cdot\text{m}$.
- Block units:
  - $K_{uu} = \Delta\bm f / \bm u \implies \text{N/m}$.
  - $K_{u\phi} = \Delta\bm f / \bm\phi \implies \text{N/rad}$.
  - $K_{\phi u} = \Delta\bm m / \bm u \implies \text{N}\cdot\text{m/m} = \text{N}$.
  - $K_{\phi\phi} = \Delta\bm m / \bm\phi \implies \text{N}\cdot\text{m/rad}$.
- The text lists: "N/m, N/rad, N m/m and N m/rad, respectively." Exact match.
- Work and energy consistency:
  $$\Delta W^T \dot\delta = (-K\delta)^T \dot\delta = -\delta^T K \dot\delta.$$
  Since $U = \frac{1}{2}\delta^T K \delta$ with symmetric $K$, $\dot U = \delta^T K \dot\delta = -W^T \dot\delta \implies W^T \dot\delta = -\dot U$.
  The sign convention is consistent: $\Delta W$ is the restoring wrench exerted by the elastic element on the body.

#### 6. Verification of Chapter Exercises

##### Exercise 1: Frame Recovery
- Translation of reference origin by $\bm c$:
  Let frame $O'$ have origin at position $\bm c$ relative to frame $O$ with axes parallel.
  For any point $P$, position vectors satisfy $\bm x = \bm x' + \bm c$.
  The spatial velocity field at $P$ is invariant:
  $$\bm v(P) = \bm v_s + \bm\omega \times \bm x = \bm v_s' + \bm\omega \times \bm x'.$$
  Substitute $\bm x = \bm x' + \bm c$:
  $$\bm v_s + \bm\omega \times (\bm x' + \bm c) = \bm v_s + \bm\omega \times \bm c + \bm\omega \times \bm x' = \bm v_s' + \bm\omega \times \bm x'.$$
  Hence:
  $$\bm v_s' = \bm v_s + \bm\omega \times \bm c.$$
  The text states: $\bm v_s' = \bm v_s + \bm\omega \times \bm c$. This confirms that $\bm c$ is the vector pointing from $O'$ to $O$ (or conversely, if $O'$ is at $\bm c$ measured in $O$, the origin of $O'$ has position $\bm x = \bm c$, so the velocity at $O'$ is $\bm v_s' = \bm v(\bm c) = \bm v_s + \bm\omega \times \bm c$). This is exact.

##### Exercise 3: Constraint Rank
- Body-fixed point $\bm X_0$ in world coordinates: $\bm x = R\bm X_0 + \bm p$.
- Sphere constraint: $g(\bm p, R) = \|\bm x - \bm c_0\|^2 - b^2 = 0$ (or $\|\bm x - \bm c_0\| - b = 0$).
- Variation with respect to pose increment $\delta = (\delta\bm p, \bm\phi)$:
  $\delta\bm x = \delta\bm p + \bm\phi \times (R\bm X_0)$.
  $$\delta g = 2(\bm x - \bm c_0) \cdot \delta\bm x = 2(\bm x - \bm c_0) \cdot \delta\bm p + 2[(\bm x - \bm c_0) \times (R\bm X_0)] \cdot \bm\phi.$$
- The gradient/Jacobian row is:
  $$J = 2\begin{pmatrix} (\bm x - \bm c_0)^T & ((R\bm X_0) \times (\bm x - \bm c_0))^T \end{pmatrix}.$$
- Rank is 1 if and only if $\bm x \ne \bm c_0$ (which is guaranteed on the sphere of radius $b > 0$).
- Two coincident copies yield linearly dependent rows ($J_2 = J_1$), maintaining rank 1, and thus cannot remove two degrees of freedom.

##### Exercise 5: Local Elastic Energy
- Given:
  $$K = \operatorname{diag}(1000, 1000, 2000, 10, 10, 20)$$
  $$\delta = (0, 0, 0.001\text{ m}, 0, 0, 0.01\text{ rad})$$
- Computation of restoring wrench $\Delta W = -K \delta$:
  $$\Delta W = -\begin{pmatrix} 1000 \times 0 \\ 1000 \times 0 \\ 2000 \times 0.001 \\ 10 \times 0 \\ 10 \times 0 \\ 20 \times 0.01 \end{pmatrix} = -\begin{pmatrix} 0 \\ 0 \\ 2.0\text{ N} \\ 0 \\ 0 \\ 0.2\text{ N}\cdot\text{m} \end{pmatrix} = (0, 0, -2.0\text{ N}, 0, 0, -0.2\text{ N}\cdot\text{m}).$$
- Computation of strain energy $U$:
  $$U = \frac{1}{2}\delta^T K \delta = \frac{1}{2}\left(2000 \times (0.001)^2 + 20 \times (0.01)^2\right) = \frac{1}{2}(0.002 + 0.002) = \frac{1}{2}(0.004) = 0.002\text{ J} = 2.0\text{ mJ}.$$
- Mechanical power check:
  $$\Delta W^T \dot\delta = -2.0 \dot u_z - 0.2 \dot\phi_z.$$
  $$\dot U = \frac{d}{dt}\left[\frac{1}{2}(2000 u_z^2 + 20 \phi_z^2)\right] = 2000 u_z \dot u_z + 20 \phi_z \dot\phi_z = 2.0 \dot u_z + 0.2 \dot\phi_z.$$
  Hence:
  $$\Delta W^T \dot\delta = -\dot U \iff \Delta W^T \dot\delta + \dot U = 0.$$
  The numerical values are exact, self-consistent, and dimensionally correct.
