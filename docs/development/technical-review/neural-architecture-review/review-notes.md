## Conceptual Corrections

State dimension, adjustable input coefficients, input rank, task-output dimension, and temporal signal rank are separate quantities. The grid example counts sites/storage, not runtime. The dense backward-pass expression is a conditional matrix-operation proxy with state, input, and horizon dependence; it excludes derivative construction and many solver-specific costs. Replacing input dimension by synergy count does not erase the state Hessian or its cubic dense products. Monte Carlo variance for a fixed integrand does not establish polynomial reinforcement-learning complexity. The two-state counterexample exposes an unstable hidden state despite a successful task output; a separately checked coupled single-input example demonstrates that input rank alone does not determine controllability.

The neural chapter separates anatomical connections, empirical task observations, computational hypotheses, and engineering analogies. M1 is not the obligatory final cortical pathway; direct cortico-motoneuronal and interneuron-mediated paths differ. Population decoding is not a torque command or proof of the downstream algorithm. Uniform planar tuning yields an exact direction; unequal angular sampling produces the explicit 16.102-degree result for a 30-degree manufactured direction. Kalman state prediction, measurement innovation, correction gain, and covariance propagation are distinct. The force-field patient evidence concerns specific online/trial-to-trial comparisons, not all cerebellar tasks. Floccular synaptic timing does not set a golf feedback clock. Concurrent striatal pathway activity challenges an exclusive go/no-go activation account without proving another optimizer.

The robot chapter replaces an unspecified adaptive update with a complete scalar plant, reference, error, control and parameter-error convention. The Lyapunov cross terms cancel, gamma has inverse-time-squared units for a dimensionless feature, and the exact-model bound prevents parameter divergence even without persistent excitation. Tracking convergence and parameter identification remain different: the zero feature gives perfect asymptotic tracking without any learning. Saturation, disturbance, nonlinear contact, and unknown input gain require fresh analysis. The supplied periodic torque policy has explicit matrix contracts and full joint-space feedback authority; it is not a coupled oscillator or demonstrated walking controller. Its shared-frequency temporal rank is at most three before centering and two afterward, independently of the number of channels. Mechanical state, task success, contact feasibility and actuator limits remain coupled.
