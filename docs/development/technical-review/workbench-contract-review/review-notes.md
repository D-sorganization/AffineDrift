## Technical Decisions

The shared catalog has six experiments. The phase-window and coordinate-source analyses are controls in the PyQt Analysis > Drift Transfer panel, not additional catalog entries. Both guides consume the same JSON; the React Open Model callback selects a model type, not numerical preset values. Shared text does not establish matching UI capabilities, matching engines or numerical parity. The Python manifest helper returns a mutable dictionary and is not evidence that every run exports metadata. Scientific status is stated as the catalog classification and required interpretation, not universal UI wiring.

The desktop transfer panel accepts only double-pendulum results. Its source-attribution summary covers the complete trajectory; its transfer summary uses the chosen window. Window integration selects saved samples inside the requested interval without interpolating endpoints. The attribution adapter rejects nonzero Coulomb friction, clamps and joint limits. Coordinates are shoulder absolute and wrist relative; terms are a coordinate-dependent equation decomposition, not distinct measured biological sources. Zero grip speed makes a motion tangent undefined even though force power is zero. One transfer helper fills a zero tangent at that numerical boundary; this convention is not a physical definition of a direction.

Counterfactual language now specifies fixed complete state for the immediate affine input difference and a changed evolving state for the forward intervention. Cross-trajectory subtraction is a valid outcome difference, but not generally the original instantaneous input term. Passive state, activation, elasticity, damping and contact require explicit intervention choices. Unchanged acceleration at one instant is not a universal falsifier: a specified nonzero prediction, output, interval and uncertainty are needed. A robustness reversal narrows a claim rather than disproving every transfer mechanism.

Two-hand reduction declares forces on the club and a common frame. About the midpoint, M = (d/2) cross (fR-fL) + mR + mL, with d=rR-rL. Coincident contact points remove the separated-force moment for bounded forces, not intrinsic contact moments or moments about another reference point. Equal and opposite forces are a pure couple; a general wrench also has resultant force. Club-side moment power uses absolute club angular velocity; actuator-pair power uses relative angular velocity. Force work, tangent impulse, negative force work and total energy balance are distinguished, with gravity counted either as work or potential energy, never both.
