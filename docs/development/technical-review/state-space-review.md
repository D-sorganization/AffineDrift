## Findings and Derivations

The original opening treated state space as abandoning physical geometry and made perfect prediction depend on current state alone. The correction instead defines sufficient state relative to a model, task, future input and existence/uniqueness domain. Minimality is separated from physical state and redundant coordinates. A point-mass force model uses (q,v), but activation, current, elasticity, hysteresis, jerk input, delays or distributed dynamics change the necessary state. An acceleration measurement is an output, not a proof of independent acceleration memory. The smooth finite-dimensional ODE class is explicitly bounded; manifolds, redundant quaternion arrays, constraints and hybrid modes are distinguished.

Under z=phi(q), zdot=Dphi v and zddot=Dphi qddot+D²phi[v,v]. The web had incorrectly assigned coordinate acceleration to TqQ and inferred universal acceleration superposition while forbidding all position superposition. The q=1+2t, z=q² counterexample gives qddot0 versus zddot8. Covariant acceleration requires a connection, the complete lifted derivative lies in T(TQ), forces are covectors, and same-state acceleration differences cancel the common Hessian term. Linear Euclidean position equations can superpose; nonlinear trajectories generally do not. Clubhead acceleration J vdot+Jdot v connects these distinctions to a physical task.

The pendulum now consistently means a point mass on a massless rod with a fixed pivot and downward angle zero. Physical torque divides by m ell²; top linearization uses eta=theta-pi, not the original absolute theta. The motor state order is (i,theta,omega), with A=[[-R/L,0,-Ke/L],[0,0,1],[Kt/J,0,-b/J]], B=(1/L,0,0). The retained angle is unnecessary for speed/current-only prediction but necessary for angle output. With the stated SI parameters its poles are 0,-99.59429702,-1.40570298. The angle integrator is semisimple, so the full zero-voltage system is stable but not attracted to a unique angle. Ideal equal numerical Kt and Ke cancel electromechanical power, giving stored-energy rate=Vin*i-Ri²-bomega². A matrix input term alone is not energy injection.
