## Lead Decisions

Chapter 6 must distinguish state propagation from sensory prediction. Linear least squares gives exact reachability only when the requested increment lies in range(B); minimum Euclidean command norm is not automatically minimum energy. A Gaussian model-bank example needs priors, covariance normalization and finite/shape contracts, explicitly excluding complete MOSAIC learning, contextual gating and HMM estimation. Weighted inverse commands are the historical proposal but are not generically exact inverses or optimal expected-cost commands. Scalar B1=1, B2=10, target increment10 and equal weights give u=5.5; model2 predicts55. Expected squared-error minimization instead uses sum(pi B.T B) and sum(pi B.T residual). Model mismatch does not universally imply unbounded drift. Delayed estimate propagation is not a complete Smith-predictor architecture; a model-output residual path and explicit plant/delay assumptions matter. Learning need not silence feedback. Imaging associations do not identify a separate inverse model per tool.

Chapter 7 coordinates: x horizontal, z up; hip=l(sin q1,cos q1), swingfoot=hip-l(sin q2,cos q2). Hip mass M, swingfoot mass m, stancefoot fixed. T=.5(M+m)l^2 v1^2+.5ml^2 v2^2-ml^2 cos(delta)v1v2. V=(M+m)gl cos q1-mgl cos q2. A=l^2[[M+m,-m cos delta],[-m cos delta,m]], c=(-ml^2 sin(delta)v2^2,+ml^2 sin(delta)v1^2), G=(-(M+m)gl sin q1,+mgl sin q2). Correct dynamics A qdd=-c-G; original listing has the opposite right-hand-side sign. det(A)=m l^4(M+m sin(delta)^2)>0. At equal angles alpha and zero velocity, qdd=(g sin(alpha)/l,0). The checked listing will model one conservative fixed-stance phase. A hybrid walker also requires contact guards, valid approach/contact conditions, impulse/reset/relabel maps and an attracting Poincare fixed point. Conservative ODEs can have periodic orbits, contrary to a helper's blanket claim. Gravity supplies potential-energy loss; inertia shapes kinetic-energy storage and coupling, and angular momentum is not energy.

Remove unsupported 60/40 clubhead-speed attribution. Along one actual trajectory vector velocity increments can be split under a declared acceleration decomposition, but speed is a nonadditive norm and previous control changes the state at which drift is evaluated. Recentring u'=u-u0 changes f'=f+Gu0. A zero-command counterfactual must specify release state/history, command meaning, constraints, horizon/contact event and outcome metric. Zero excitation does not erase existing activation or tendon energy. No universal passive/active assignments to golf phases.

Chapter 10: finite-horizon Ito HJB includes .5 tr(GG.T Hess V), terminal cost and information assumptions; stochastic maximum principles also exist. Additive full-state LQ noise can leave feedback gains unchanged while changing value/covariance; sustained costly noise generally makes infinite undiscounted total cost diverge, so stationary average cost is distinct. Control-dependent diffusion changes the Riccati problem: dx=(ax+bu)dt+sigma*u*dW gives K=bp/(r+sigma^2p), and pdot+2ap+q-b^2p^2/(r+sigma^2p)=0. Diffusion has state/sqrt(time) units; sigma has sqrt(time) units when u has state/time units. No universal empirical noise coefficient. CARE needs Q PSD, R PD, stabilizability and detectability. Double integrator Q=diag(1,0), R=1 gives P=[[sqrt2,1],[1,sqrt2]], K=[1,sqrt2]: zero instantaneous velocity cost does not make velocity irrelevant to future position. Minimum jerk and minimum variance optimize different objectives. Static variational free energy equals KL(q||posterior)-log evidence; minimizing q at fixed observations is not an action-selection rule.
