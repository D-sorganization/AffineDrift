#### A. Single-Rate Recurrence & Closed Form
* **Definition:**
  $$e_k = p_k - x_k, \qquad x_{k+1} = a x_k + b e_k = (a - b)x_k + b p_k$$
  Units: $p_k, x_k, e_k$ in degrees; $a, b$ dimensionless. Units match consistently.
* **Closed-form with constant $p$ and $\lambda = a - b$:**
  $$x_\infty = \frac{b p}{1 - (a - b)} = \frac{b p}{1 - a + b}$$
  $$e_\infty = p - x_\infty = \frac{(1 - a)p}{1 - a + b}$$
  $$x_k - x_\infty = \lambda(x_{k-1} - x_\infty) \implies x_k = x_\infty + (x_0 - x_\infty)\lambda^k$$
  *Verification:* At $k=0$, $x_0 = x_\infty + x_0 - x_\infty = x_0$. At $k=1$, $x_1 = x_\infty(1-\lambda) + \lambda x_0 = b p + (a-b)x_0$.
  *Calculations:* $a = 0.98, b = 0.05, p = 30^\circ$:
  $$1 - a + b = 1 - 0.98 + 0.05 = 0.07 = \frac{7}{100}$$
  $$x_\infty = \frac{0.05 \times 30}{0.07} = \frac{1.5}{0.07} = \frac{150}{7} \approx 21.42857^\circ$$
  $$e_\infty = \frac{0.02 \times 30}{0.07} = \frac{0.6}{0.07} = \frac{60}{7} \approx 8.5714^\circ$$
  Values, signs, and asymptotic formulas are exact.

* **Spontaneous recovery under clamp:**
  If $e_k = 0$, $x_{f,j} = a_f^j x_{f,0} = -c a_f^j$, and $x_{s,j} = a_s^j x_{s,0} = c a_s^j$.
