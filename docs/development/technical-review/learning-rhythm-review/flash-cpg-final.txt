This review audits mathematical derivations, physical dimensions, sign conventions, boundary/bifurcation conditions, code implementation, and biological/biomechanical claims.

### 1. Mathematical Derivations, Equations, and Signs

1. **Equilibrium Point ($x_*$)**:
   $$\tau_1\dot x_i = -x_i - \beta v_i - w y_j + u = 0, \quad \tau_2\dot v_i = -v_i + y_i = 0$$
   With $x_i > 0$, $y_i = x_i$, so $v_i = x_i$. Setting $x_1 = x_2 = x_*$:
   $$-x_* - \beta x_* - w x_* + u = 0 \implies x_* = \frac{u}{1+\beta+w}.$$
   *Verification:* **Correct** for $u > 0, \beta \ge 0, w \ge 0$.

2. **Linearization & Modal Jacobians ($J_+, J_-$)**:
   In the active orthant ($x_1, x_2 > 0$):
   $$\dot x_1 = \frac{1}{\tau_1}(-x_1 - \beta v_1 - w x_2 + u), \quad \dot v_1 = \frac{1}{\tau_2}(-v_1 + x_1)$$
   $$\dot x_2 = \frac{1}{\tau_1}(-x_2 - \beta v_2 - w x_1 + u), \quad \dot v_2 = \frac{1}{\tau_2}(-v_2 + x_2)$$
   Let $s_x = x_1 + x_2$, $s_v = v_1 + v_2$, $d_x = x_1 - x_2$, $d_v = v_1 - v_2$:
   - Sum dynamics:
     $$\tau_1 \dot s_x = -(1+w)s_x - \beta s_v + 2u, \quad \tau_2 \dot s_v = s_x - s_v$$
     $$J_+ = \begin{pmatrix} -(1+w)/\tau_1 & -\beta/\tau_1 \\ 1/\tau_2 & -1/\tau_2 \end{pmatrix}$$
     $$\operatorname{tr} J_+ = -\frac{1+w}{\tau_1} - \frac{1}{\tau_2} < 0, \quad \det J_+ = \frac{1+w+\beta}{\tau_1 \tau_2} > 0.$$
     Sum mode is strictly Hurwitz stable.
   - Difference dynamics:
     $$\tau_1 \dot d_x = -(1-w)d_x - \beta d_v = (w-1)d_x - \beta d_v, \quad \tau_2 \dot d_v = d_x - d_v$$
     $$J_- = \begin{pmatrix} (w-1)/\tau_1 & -\beta/\tau_1 \\ 1/\tau_2 & -1/\tau_2 \end{pmatrix}$$
     $$\operatorname{tr} J_- = \frac{w-1}{\tau_1} - \frac{1}{\tau_2}, \quad \det J_- = \frac{-(w-1) - (-\beta)}{\tau_1 \tau_2} = \frac{1+\beta-w}{\tau_1 \tau_2}.$$
   *Verification:* **Exact match**.

3. **Bifurcation / Instability Range**:
   $J_-$ has eigenvalues with positive real parts if either $\det J_- < 0$ or ($\operatorname{tr} J_- > 0$ and $\det J_- > 0$).
   - $\operatorname{tr} J_- > 0 \iff w - 1 > \frac{\tau_1}{\tau_2} \iff w > 1 + \frac{\tau_1}{\tau_2}$.
   - $\det J_- > 0 \iff w < 1 + \beta$.
   Together: $1 + \frac{\tau_1}{\tau_2} < w < 1 + \beta$ generates a Hopf bifurcation condition across $\operatorname{tr} J_- = 0$.
   *Verification:* **Correct**.

4. **Phase Oscillator Difference Dynamics**:
   $$\dot\phi_i = \omega_i + \sum_j K_{ij} \sin(\phi_j - \phi_i - \psi_{ij})$$
   For $N=2$, $\psi_{12} = \psi_{21} = 0$, $K_{12} = K_{21} = K > 0$, $\delta = \phi_2 - \phi_1$:
   $$\dot\phi_1 = \omega_1 + K \sin(\phi_2 - \phi_1) = \omega_1 + K \sin\delta$$
   $$\dot\phi_2 = \omega_2 + K \sin(\phi_1 - \phi_2) = \omega_2 - K \sin\delta$$
   $$\dot\delta = \dot\phi_2 - \dot\phi_1 = (\omega_2 - \omega_1) - 2K \sin\delta = \Delta\omega - 2K \sin\delta.$$
   - Equilibrium: $\sin\delta^* = \frac{\Delta\omega}{2K}$, requiring $|\Delta\omega| \le 2K$.
   - Linearization around $\delta^*$: $\frac{d}{d\delta}(\dot\delta) = -2K \cos\delta^*$.
   - For stability: $-2K \cos\delta^* < 0 \iff \cos\delta^* > 0$.
   *Verification:* **Exact and rigorous**. Boundary $|\Delta\omega| = 2K \implies \cos\delta^* = 0$ (saddle-node bifurcation; nonhyperbolic).

### 2. Units and Dimensional Homogeneity

- **Matsuoka rate model**:
  - $\tau_1, \tau_2$: dimensions of time $[T]$.
  - $\dot x_i, \dot v_i$: $[1/T]$.
  - $x_i, v_i, y_i, u, \beta, w$: dimensionless normalized rate quantities.
  - RHS of $\tau_1 \dot x_i$ has all dimensionless terms; dividing by $\tau_1$ gives $[1/T]$.
- **Phase coupling model**:
  - $\phi_i, \psi_{ij}$: dimensionless radians.
  - $\omega_i$: $[\mathrm{rad}/T] \equiv [1/T]$.
  - $K_{ij}$: $[\mathrm{rad}/T] \equiv [1/T]$.
  - Argument of sine: dimensionless.
- **Laplacian matrix $L$**:
  - Elements have units of $K_{ij}$ ($[1/T]$).
  - $\dot\eta = -L\eta$ is dimensionally consistent ($[1/T] \times [\mathrm{dimensionless}] = [1/T]$).
