### Identified Duplication Within css/

1. **Responsive rules split across `mobile.css` and `responsive.css`**: Both files contain
   `@media` queries. These should be consolidated into a single `responsive.css`.

2. **`overrides.css` (484 lines)**: Contains Quarto-specific overrides mixed with custom styles.
   Many may be addressable by using Quarto's built-in variables instead.

3. **`laymans-terms.css` vs `critics-corner.css`**: Both are section-specific files with
   similar patterns (callout boxes, special headers). Could share a base pattern.

4. **`utilities.css` (349 lines)**: Utility classes that may overlap with Bootstrap utilities
   already provided by Quarto's Bootstrap base.

## Recommended Reduction Plan

### Phase 1: Remove Duplicates (Easy, ~2,100 lines saved)

- Delete `src/css/` directory entirely
- Update any references in build scripts or HTML

### Phase 2: Consolidate Responsive Rules (Medium, ~100 lines saved)

- Merge `mobile.css` into `responsive.css`
- Single file for all `@media` queries

### Phase 3: Audit Overrides (Hard, ~150 lines potential)

- Review `overrides.css` rule by rule
- Check if equivalent can be achieved with Quarto SCSS variables in `custom.scss`
- Remove rules that duplicate Bootstrap utilities available from Quarto

### Phase 4: Utility Deduplication (Medium, ~100 lines potential)

- Compare `utilities.css` against Bootstrap utilities (`.d-flex`, `.text-center`, etc.)
- Remove any duplicates

## Current Variable Conflict

The `base.css` file uses a "Modern Scientific" palette with CSS custom properties:
```css
--primary-dark: #1a1a2e;
--accent-blue: #3282b8;
```

The `custom.scss` file uses Okabe-Ito palette SCSS variables. Both are loaded and
both define colors. Long-term fix: consolidate to one system (tracked in issue #1462).
