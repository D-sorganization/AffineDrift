Models Overview

This section contains mathematical models and simulations implemented across various platforms for analyzing golf biomechanics, control-affine systems, and multibody dynamics. Each model category provides tools and documentation for understanding the underlying physics and control principles. Click on any model to expand and view details.

Matlab Simulink Models

Control-affine system models, drift-input decomposition simulations, and golf swing dynamics implemented in Matlab Simulink. These models implement the theoretical framework developed in the Drifter Manifesto series, providing numerical simulations and analysis tools. Includes comprehensive documentation of numerical routines, model structure, and supporting technical notes.

View Details →

MuJoCo Models

Physics-based simulations using MuJoCo (Multi-Joint dynamics with Contact) for biomechanical analysis, including golf swing models, pendulum systems, and multibody dynamics simulations. MuJoCo provides fast and accurate physics simulation for model-based optimization and analysis.

View Details →

Drake Models

Robotics and control system models implemented in Drake, focusing on underactuated systems, manipulation, and control-affine dynamics. Drake is an open-source toolbox from MIT's Robot Locomotion Group that provides tools for modeling, simulation, and control of complex robotic systems.

View Details →

Pinocchio Models

Rigid body dynamics and kinematics models using Pinocchio, including forward/inverse dynamics, Jacobian computations, and constraint handling for multibody systems. Pinocchio provides efficient algorithms for robot dynamics and kinematics, based on Roy Featherstone's "Rigid Body Dynamics Algorithms."

View Details →

Pendulum Models

Pendulum-based models and simulations that serve as simplified analogs for understanding golf swing dynamics, including single, double, and multi-link pendulum systems. These models provide insights into control-affine systems, drift-input decomposition, and the fundamental physics of underactuated multibody systems.

View Details →

OpenSim Models

Biomechanics simulation models using OpenSim, a freely available, open-source software platform for modeling, simulating, and analyzing the neuromusculoskeletal system. OpenSim enables building and analyzing musculoskeletal models, performing inverse kinematics and dynamics, and simulating movement.

View Details →

MyoSim Models

Muscle-driven movement simulation models using MyoSim, an open-source software library for simulating muscle-driven movement. MyoSim provides tools for biomechanical modeling and analysis, enabling researchers to build and simulate models of muscle-tendon systems and analyze muscle activation patterns.

View Details →

Wrist Universal Joint Models

Interactive application modeling the wrist as a universal joint with proper kinematics. Explore how grip angle and wrist deviation affect torque transmission to the club's shaft axis and high-inertia axis, with real-time visualization and calculations.
