# AffineDrift Project Charter

## End Goal

Publish source-bounded scientific writing and executable companion explanations
for golf mechanics, multibody dynamics and nonlinear control. Keep assumptions,
derivations, citations, numerical evidence and limitations reviewable together,
as described in [README.md](../../README.md) and [SPEC.md](../../SPEC.md).

This initial feature list covers the impact/acoustics program and its deferred
validation dependency. It is not an exhaustive inventory of the portfolio;
feature counts describe only the listed scopes, not overall scientific completion.

## Non-Goals

- Replace the reusable Tools kernels or UpstreamDrift's executable studies.
- Treat synthetic models, numerical agreement or issue closure as physical validation.
- Claim player-specific acoustic sweetness without qualified controlled evidence.
- Authorize collection, participant recruitment, funding or independent approval
  through a project-status update.
