## 2. Container View (C4Container)

```mermaid
C4Container
  title Container Diagram: AffineDrift Core Components

  Person(reader, "Reader / Researcher", "Web user or mathematical reviewer.")

  Container_Boundary(c1, "AffineDrift") {
    Container(quarto_site, "Quarto Web Application", "Quarto, HTML, CSS, JavaScript (Three.js, D3)", "Static educational textbook with interactive 3D/2D visualizers, KaTeX math, and WCAG-compliant accessible pages.")
    Container(control_engine, "Affine Control Engine", "Python 3.12, NumPy, SciPy", "Core trajectory optimization, iLQR/DDP solvers, drift-control ratio (DCR) analysis, and double-pendulum state spaces.")
    Container(trust_registry, "Trust & Claim Verification Engine", "Python 3.12, JSONSchema", "Adjudication ledgers, falsification atlases, citation integrity checks, and scientific evidence boundaries.")
    Container(mocap_projection, "Mocap & Companion Projection", "Python 3.12, JSON", "Read-only ingestion, schema validation, and presentation of upstream markerless mocap artifacts and release catalogs.")
    Container(cli_tools, "Development & Quality Gate Tools", "Python 3.12, Pytest, Ruff, Black", "Pre-commit validators, title casing checkers, spec changelog guards, and root hygiene linters.")
  }

  System_Ext(upstream_drift, "UpstreamDrift", "Upstream physics simulation repository.")
  System_Ext(pages_host, "GitHub Pages", "Web host.")

  Rel(reader, quarto_site, "Reads articles and interacts with visualizers via", "HTTPS")
  Rel(quarto_site, control_engine, "Embeds precomputed trajectories and reproducible numerical outputs from", "JSON / QMD code cells")
  Rel(trust_registry, quarto_site, "Supplies verified claim status, critique ledgers, and evidence tables to", "JSON / Includes")
  Rel(mocap_projection, upstream_drift, "Validates release manifests and verified SHA-256 digests against", "HTTPS / Raw Manifest")
  Rel(trust_registry, mocap_projection, "Audits upstream provenance and companion qualification using", "Internal Python API")
  Rel(cli_tools, trust_registry, "Enforces digest and schema freshness in CI via", "CLI scripts")
  Rel(quarto_site, pages_host, "Publishes verified build artifacts to", "GitHub Actions")
```

| --- | --- | --- | --- |
