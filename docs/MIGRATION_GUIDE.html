1 Quarto Migration Guide

This document explains the migration from manual HTML to Quarto-based workflow.

1.1 What Changed

1.1.1 Before (Manual HTML)

  • Articles written in LaTeX
  • Manually converted to HTML
  • HTML files edited directly
  • Deployed from repository root

1.1.2 After (Quarto)

  • Articles written as .qmd files (Quarto Markdown)
  • Automatically converted to HTML by Quarto
  • No manual HTML editing needed
  • Deployed from docs/ directory

1.2 Benefits of Quarto

  1. No More Manual Conversion: Write articles in Markdown or convert from LaTeX automatically
  2. Native LaTeX Math: Full LaTeX math support with MathJax
  3. Better Workflow: Edit .qmd → Run build → Deploy (no manual HTML editing)
  4. Code Integration: Embed Python, R, or Julia code with live outputs
  5. Consistent Formatting: Quarto handles all HTML generation consistently
  6. Interactive Elements: Easy to embed charts, plots, and interactive tools
  7. Version Control Friendly: Markdown source files are easier to diff than HTML

1.3 File Organization

Old Structure:                  New Structure:
├── index.html                  ├── index.qmd
├── articles.html               ├── qmd/articles.qmd
├── theory-part1.html           ├── qmd/theory-part1.qmd (to be created)
├── content/ (LaTeX)            ├── latex_src/ (archived LaTeX)
├── styles.css                  ├── styles.css (preserved)
├── script.js                   ├── script.js (preserved)
                                ├── _quarto.yml (configuration)
                                ├── scripts/build.sh (build automation)
                                └── docs/ (generated, deployed)

1.4 How to Work with the New System

1.4.1 Creating a New Article

  1. Start from the template:

    cp qmd/_template_article.qmd qmd/my-new-article.qmd

  2. Edit the YAML frontmatter:

    ---
title: "Your Article Title"
author: "AffineDrift"
date: "2024-01-01"
description: "Brief description"
format:
  html:
    toc: true
    html-math-method: mathjax
---

  3. Write content in Markdown:

    ## Introduction

This is a paragraph with inline math: $E = mc^2$

And display math:
$$
\frac{d}{dt}\frac{\partial L}{\partial \dot{q}} - \frac{\partial L}{\partial q} = \tau
$$

### Code Example

```python
import numpy as np
theta = np.linspace(0, 2*np.pi, 100)

    ```

  4. Build and preview:

    ./scripts/build.sh
quarto preview

1.4.2 Converting Existing LaTeX Articles

  1. Place LaTeX files in latex_src/ (already done for existing files)

  2. Run the conversion script:

    python3 scripts/convert_latex_to_qmd.py

  3. Review the generated .qmd files in qmd/:

    • Check formatting
    • Fix any conversion issues
    • Adjust YAML frontmatter
    • Add categories/tags

  4. Build and verify:

    ./scripts/build.sh

1.4.3 Updating the Site

Old workflow: 1. Edit HTML file directly 2. Commit and push 3. GitHub deploys

New workflow: 1. Edit .qmd file 2. Build locally (optional): ./scripts/build.sh 3. Commit and push 4. GitHub Actions builds and deploys automatically

1.5 Preserving Custom Design

All custom styling and JavaScript has been preserved:

  • styles.css → Included via _quarto.yml
  • script.js → Included via _quarto.yml
  • Custom fonts → Included in Quarto config
  • Logo and images → Copied to docs/ during build
  • Interactive tools → Available in tools/ directory

Quarto generates the HTML structure, but your custom CSS controls the appearance.

1.6 GitHub Pages Configuration

Important: Update your GitHub Pages settings:

  1. Go to repository Settings → Pages
  2. Set Source to: Deploy from a branch
  3. Set Branch to: main (or your default branch)
  4. Set Folder to: /docs
  5. Save

This tells GitHub Pages to serve from docs/ instead of root.

1.7 Build Commands Reference

# Basic build
./scripts/build.sh

# Clean build (removes previous build)
./scripts/build.sh --clean

# Convert LaTeX and build
./scripts/build.sh --convert-latex

# Preview site locally
quarto preview

# Render without build script
quarto render

1.8 Troubleshooting

1.8.1 Build fails with “quarto: command not found”

Solution: Install Quarto from https://quarto.org/docs/get-started/

1.8.2 Build fails with “pandoc: command not found”

Solution: sudo apt-get install pandoc or brew install pandoc

1.8.3 Math equations not rendering

Solution: - Ensure YAML has html-math-method: mathjax - Check that equations use $...$ or $$...$$ - Verify no LaTeX-only commands without Quarto equivalents

1.8.4 Custom CSS not applied

Solution: - Check _quarto.yml includes css: - styles.css - Ensure styles.css is in repository root - Rebuild with ./scripts/build.sh --clean

1.8.5 Images/tools not showing

Solution: - Check paths are relative (e.g., ../pics/image.png from qmd/) - Verify build.sh copies tools/, pics/, logo/ to docs/ - Ensure files are committed to repository
