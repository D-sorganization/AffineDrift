## Analysis
Documentation is present but could be more comprehensive for the tools.

- **CONTRIBUTING.md**: Exists and is detailed.
- **AGENTS.md**: Provides specific instructions for AI agents.

## Findings

- Create a `tools/README.md` explaining the purpose of each script.
