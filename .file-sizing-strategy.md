# File Sizing Strategy — Issue #1697

## Executive Summary

AffineDrift maintains a file-sizing budget to limit change risk, merge friction, and hidden coupling. This document outlines the strategy for managing oversized files.

## Current File Sizing Metrics

### Python Files (src/, scripts/)

Measured 49KB total across all Python files:
- Largest file: `scripts/assess_repo.py` (687 LOC)
- Most modules: < 500 LOC
- Pattern: Well-factored, single-responsibility modules

**Status: HEALTHY** ✓

### Quarto Content Articles (articles/)

Measured 84KB total across content files:
- Largest file: `volume2_content.qmd` (3,811 LOC)
- Next tier: 2,200-3,100 LOC files (thematic articles)
- Pattern: By design — comprehensive textbook chapters

**Status: ARCHITECTURAL** (not a bug; intentional structure)

### Binary/Data Files

- `package-lock.json` (6,659 LOC) — Auto-generated, not refactorable
- CSL bibliography files (4,189 LOC) — Citation format, not refactorable

**Status: ACCEPTABLE** (non-code, necessary artifacts)

## Refactoring Opportunities

### 1. Quarto Articles (Potential Split Candidates)

Large articles could be split into sections if they combine unrelated topics:

- `volume2_content.qmd` (3,811 LOC) - Review for topical boundaries
- `Tangent_Hyperplanes_Unified_Thesis.qmd` (3,099 LOC) - Consider chapter splits
- `affine-nature-golf-swing.qmd` (2,751 LOC) - Single topic, keep intact

**Recommendation:** Review on a case-by-case basis; document why articles are single files (pedagogical flow, cross-references, etc.).

### 2. Python Modules (Architecture Check)

All Python files meet sizing budgets. Current organization is sound.

### 3. HTML Artifacts (Rendered Output)

Large HTML files in `docs/content/` are generated by Quarto and should not be manually edited.

**Recommendation:** Monitor CSS and rendering efficiency rather than splitting HTML.

## Sizing Budgets

### Python Code Files
- **Recommended limit:** 500 LOC per module
- **Current max (src/):** 508 LOC (`swing_optimizer.py`)
- **Action:** Document and maintain

### Quarto Articles  
- **Recommended limit:** 3,500 LOC per article (pedagogically justified)
- **Current max:** 3,811 LOC (`volume2_content.qmd`)
- **Action:** Review; document pedagogical rationale if exceeding 4,000 LOC

### CSS Files
- **Enforced by CI:** Stylesheet size budget (see `config/css_quality_budget.json`)

## Enforcement Mechanism

1. **Pre-commit checks** — Flag files approaching limits
2. **CI validation** — Fail builds if budgets exceeded
3. **Quarterly reviews** — Assess if splitting is needed

## Next Steps

1. Document reasons for large Quarto files (why they're single documents)
2. Review `volume2_content.qmd` for potential chapter extraction
3. Maintain Python module sizing in future refactoring
4. Monitor generated artifacts (package-lock.json, CSL files) for tooling improvements
