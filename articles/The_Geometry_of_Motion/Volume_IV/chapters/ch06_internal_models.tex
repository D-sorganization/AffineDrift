\section{State Prediction and Sensory Prediction}

A discrete forward dynamics model propagates state,
\begin{equation}
 \hat x_{k+1|k}=\hat f(\hat x_{k|k},u_k),\qquad
 \hat y_{k+1|k}=\hat h(\hat x_{k+1|k}).
 \label{eq:ch6:forward-model}
\end{equation}
The second map predicts a sensory measurement. State and measurement need not
have the same dimension or units. Measured prediction error is
$y_{k+1}-\hat y_{k+1|k}$; it is not generally a directly observed full-state
error. Process uncertainty, sensor noise, delay and model error contribute
different terms to an estimator, as in the neural architecture chapter.

A forward model is useful for comparing candidate commands, interpreting
delayed observations and detecting unexpected outcomes. None of these uses
implies exact prediction or proves a neural implementation. A model may be
learned, identified from data, analytically specified, or a combination.

\section{Inversion Is a Feasibility and Selection Problem}

For $x_{k+1}=Ax_k+Bu_k$, define $d=x_{k+1}^{\mathrm{des}}-Ax_k$.
An exact inverse command exists precisely when $d\in\operatorname{range}B$.
If $B$ has a null space, multiple commands may produce the same increment.
The minimum Euclidean-norm least-squares solution and its residual are
\begin{equation}
 u_*=B^\dagger d,\qquad r=d-Bu_*.
 \label{eq:ch6:inverse-model}
\end{equation}
A nonzero residual means this requested one-step state is not exactly
reachable in the chosen linear model. It does not prove multi-step
uncontrollability. The sampled matrices depend on the discretization and
sampling interval; a zero position block in an explicit-Euler input matrix
is not a universal property of sampled mechanical systems.

Minimum command norm depends on command coordinates and units. It is not
minimum muscle energy without an appropriate physical cost and model.
Actuator bounds, contact forces and joint constraints introduce a constrained
optimization problem. Nonlinear inversion can have several branches or no
solution; writing $f^{-1}$ without a domain and selection rule hides these issues.

\section{Context Inference and the MOSAIC Hypothesis}

MOSAIC proposes paired predictive and command models with context-dependent
responsibility~\cite{WolpertKawato1998,HarunoMosaic2001Review}. The developed
architecture includes learning and contextual selection before and during
movement. Its weighted inverse commands are a proposed construction tested
in specified simulations, not a general inversion theorem.
Visuomotor-tool learning has been associated with changing cerebellar activity
in an imaging experiment~\cite{Imamizu2000}. That association alone does not
identify a separate forward--inverse pair for every tool or establish the
architecture uniquely.

For a fixed bank with prediction $\mu_i$, observed vector $z$, covariance
$R_i\succ0$ and prior $\pi_i>0$, a Gaussian observation model gives
\begin{align}
 \ell_i&=\log\pi_i-\tfrac12\left[
 (z-\mu_i)^TR_i^{-1}(z-\mu_i)+\log\det R_i+n\log(2\pi)\right],\\
 w_i&=\frac{\exp\ell_i}{\sum_j\exp\ell_j}.
\end{align}
Covariance makes the quadratic residual dimensionless; its determinant
normalizer matters when covariances differ. Equal priors and a common identity
covariance reduce this to normalized exponentials of negative squared errors.
Those special assumptions should not be silently applied to measurements
with mixed units. All likelihood densities must use the
same measurement coordinates and reference measure; a common invertible
change of units transforms means and covariances together and its common
density Jacobian cancels in the posterior weights. A prior conditioned on
contextual cues differs from a posterior based on the new observation.
Repeated measurements require a
specified context transition model and dependence assumptions; this function
does not learn or propagate them.

\begin{lstlisting}[language=Python, caption={Linear Inversion and Gaussian Model Responsibilities.}]
from dataclasses import dataclass
import numpy as np
from scipy.special import logsumexp


def checked_vector(value: np.ndarray, size: int) -> np.ndarray:
    """Require a finite vector of the specified dimension."""
    result = np.asarray(value, dtype=float)
    if result.shape != (size,) or not np.all(np.isfinite(result)):
        raise ValueError("Invalid finite-vector contract")
    return result


@dataclass
class LinearPair:
    """Fixed discrete dynamics and an unconstrained least-squares inverse."""

    A: np.ndarray
    B: np.ndarray

    def __post_init__(self) -> None:
        self.A = np.array(self.A, dtype=float, copy=True)
        self.B = np.array(self.B, dtype=float, copy=True)
        if self.A.ndim != 2 or self.A.shape[0] == 0:
            raise ValueError("A must be a nonempty square matrix")
        size = self.A.shape[0]
        if self.A.shape != (size, size):
            raise ValueError("A must be square")
        if self.B.ndim != 2 or self.B.shape[0] != size:
            raise ValueError("B must have the same state dimension")
        if self.B.shape[1] == 0:
            raise ValueError("At least one command coordinate is required")
        if not (np.isfinite(self.A).all() and np.isfinite(self.B).all()):
            raise ValueError("Dynamics matrices must be finite")

    def predict(self, x: np.ndarray, u: np.ndarray) -> np.ndarray:
        """Predict state with float arithmetic, including integer inputs."""
        state = checked_vector(x, self.A.shape[0])
        command = checked_vector(u, self.B.shape[1])
        return self.A @ state + self.B @ command

    def inverse(self, x: np.ndarray, target: np.ndarray) -> tuple:
        """Return minimum-norm command and unachieved state residual."""
        state = checked_vector(x, self.A.shape[0])
        desired = checked_vector(target, self.A.shape[0])
        increment = desired - self.A @ state
        command = np.linalg.lstsq(self.B, increment, rcond=None)[0]
        return command, increment - self.B @ command


def gaussian_log_likelihoods(errors: np.ndarray,
                             covariances: np.ndarray) -> np.ndarray:
    """Compute Gaussian log likelihoods with batched Cholesky solves."""
    count, size = errors.shape
    covariance = np.asarray(covariances, dtype=float)
    if covariance.shape != (count, size, size):
        raise ValueError("One square covariance per prediction is required")
    if not np.isfinite(covariance).all():
        raise ValueError("Covariances must be finite")
    if not np.allclose(covariance, covariance.swapaxes(-1, -2),
                       rtol=0, atol=1e-12):
        raise ValueError("Covariances must be symmetric")
    try:
        lower = np.linalg.cholesky(covariance)
    except np.linalg.LinAlgError as error:
        raise ValueError("Covariances must be positive definite") from error
    whitened = np.linalg.solve(lower, errors[..., None])[..., 0]
    logdet = 2 * np.log(np.diagonal(lower, axis1=1, axis2=2)).sum(axis=1)
    return -0.5 * ((whitened**2).sum(axis=1)
                   + logdet + size * np.log(2 * np.pi))


def responsibilities(predictions: np.ndarray, observation: np.ndarray,
                     covariances: np.ndarray, priors: np.ndarray) -> np.ndarray:
    """Normalize a fixed bank's Gaussian posterior; no model learning."""
    means = np.asarray(predictions, dtype=float)
    if means.ndim != 2 or min(means.shape) == 0:
        raise ValueError("Predictions must be a nonempty model-by-state array")
    if not np.isfinite(means).all():
        raise ValueError("Predictions must be finite")
    observed = checked_vector(observation, means.shape[1])
    prior = checked_vector(priors, means.shape[0])
    if np.any(prior <= 0) or not np.isclose(prior.sum(), 1, rtol=0, atol=1e-12):
        raise ValueError("Priors must be positive and sum to one")
    logits = np.log(prior) + gaussian_log_likelihoods(observed - means, covariances)
    if not np.isfinite(logits).all():
        raise ValueError("Likelihood exceeds numerical range")
    logits -= logits.max()
    return np.exp(logits - logsumexp(logits))
\end{lstlisting}

Two identical zero-error predictions with scalar variances $1,4$ and equal
priors receive weights $2/3,1/3$: the broader density has half the peak
likelihood. Logarithmic normalization avoids the all-zero likelihood problem
for large residuals, but does not remove finite-precision limits or model misspecification.

\subsection{Mixing Predictions Does Not Invert a Plant}

Consider scalar $A_1=A_2=0$, $B_1=1$, $B_2=10$, and target $10$.
The individual exact commands are $10$ and $1$. Equal-weight mixing gives
$u=5.5$, which produces $55$ under model 2. Neither averaging commands nor
averaging forward models establishes the correct command for the actual
plant. Given fixed model probabilities, minimizing expected squared one-step
error instead yields, when the matrix is invertible,
\begin{equation}
 u_* =\left(\sum_i w_i B_i^TB_i\right)^{-1}
             \sum_i w_i B_i^T(x_{\rm des}-A_i x).
\end{equation}
For this example $u_*=110/101$, different from the inverse mixture. This
calculation assumes fixed probabilities, unconstrained commands and a
specified quadratic loss; it is not a complete adaptive or dual-control policy.

\section{Learning and Delayed Feedback}

Feedback-error learning uses a feedback command as a training signal for a
feedforward inverse path~\cite{Kawato1987}. Whether it converges, what it
learns and how much residual feedback remains depend on the plant, learning
rule, excitation, noise and approximation. It does not imply that feedback
always falls silent, nor that sensory prediction error and command error are
interchangeable without a model of their relationship.

Starting from an estimated delayed state, an engineering predictor can propagate
\begin{equation}
 \hat x(t)=\hat x(t-\tau)+\int_{t-\tau}^{t}
             \hat f(\hat x(s),u(s))\,ds.
 \label{eq:ch6:smith-predictor}
\end{equation}
This requires input history and a specified estimator at $t-\tau$.
It is state propagation, not by itself a complete Smith-predictor loop.
In one classical linear input-delay construction, a plant has transfer
$e^{-s\tau}G(s)$ and the controller receives the effective feedback
\begin{equation}
 y_{\rm eff}=y+\bigl(G_m-e^{-s\tau}G_m\bigr)u.
\end{equation}
The measured-minus-delayed-model residual corrects the delay-free model
output. Under exact matching $G_m=G$, known constant delay and compatible
initial histories, this feedback becomes $G_m u$. Internal stability and
robustness still need analysis; cancellation reasoning alone is insufficient
for unstable plants or model mismatch. Neural delay compensation is a
hypothesis to test, not established by drawing this engineering loop.

For golf, the relevant question is how prediction error, delay, changing
contacts and actuator history affect a specified task outcome. The same
trajectory can be consistent with several combinations of anticipatory
commands and feedback. Perturbations and measurements must distinguish those
alternatives before assigning a neural algorithm or a passive contribution.
