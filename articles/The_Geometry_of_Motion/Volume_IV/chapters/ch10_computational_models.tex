\chapter[Computational Models of Motor Control]{Computational Models\\of Motor Control}
\label{ch:computational}

\begin{gomdraftnotice}
This chapter distinguishes computational objectives, mathematical solutions
and proposed neural implementations. The executable example solves a
deterministic full-state linear-quadratic problem. Stochastic and biological
extensions require the additional assumptions stated below.

\section{What a Computational Theory Specifies}

A model must specify the plant, available information, objective, admissible
commands and learning assumptions. A similar movement trajectory can arise
from different choices. Smoothness, adaptation or task-dependent variability
alone does not identify a unique objective or neural algorithm.

These classes can overlap. An optimal controller can use a forward model and
a restricted actuator basis. A fitted low-rank signal factorization is not
itself a controller. A proposed cortical or cerebellar implementation needs
evidence beyond a behavioral fit.

\section{Stochastic Optimal Feedback Control}

Todorov and Jordan's account frames coordination in terms of task performance
under uncertainty~\cite{TodorovJordan2002}. Its simulations use specified
linear dynamics, multiplicative command noise and delayed/noisy observations.
This is a computational-level account, not a demonstration that the nervous
system solves an exact optimization problem in real time.

For a fully observed It\^o diffusion, write
\begin{align}
 dx_t&=f(x_t,u_t,t)\,dt+\Sigma(x_t,u_t,t)\,dW_t,\\
 J^\pi(t,x)&=\mathbb E\left[\Phi(x_T)+
       \int_t^T L(x_s,u_s,s)\,ds\mid x_t=x\right].
 \label{eq:ch10:ofc}
\end{align}
The policy must be adapted to the declared information and obey the admissible
input constraints. Brownian increments have covariance $I\,dt$, so
$\Sigma$ has state units per square root of time. Dependence on $x$ alone is
state-dependent noise; command-dependent motor noise requires explicit
dependence on $u$ or an appropriate actuator-state model.

When the value $V=\inf_\pi J^\pi$ is sufficiently smooth and dynamic
programming applies, its Hamilton--Jacobi--Bellman equation is
\begin{equation}
 -V_t=\min_{u\in\mathcal U}\left[
 L+\nabla V^Tf+\tfrac12\operatorname{tr}
       (\Sigma\Sigma^T\nabla^2V)\right],\qquad V(T,x)=\Phi(x).
\end{equation}
Nonsmooth problems need an appropriate generalized solution concept.
Partial observations change the information state; substituting an arbitrary
state estimate into a full-state policy is not generally optimal. Stochastic
maximum principles also exist. Deterministic Pontryagin conditions cannot
simply be applied to one noisy sample path to solve the expected-cost problem,
but it is incorrect to describe HJB as the only stochastic approach.

\section{A Checked Deterministic LQR Example}

Consider $\dot x=Ax+Bu$ with measured state and
\begin{equation}
 J=\int_0^\infty(x^TQx+u^TRu)\,dt,
 \qquad Q\succeq0,\quad R\succ0.
\end{equation}
Under stabilizability of $(A,B)$ and detectability of $(Q^{1/2},A)$,
the stabilizing Riccati solution satisfies
\begin{equation}
 A^TP+PA-PBR^{-1}B^TP+Q=0,\qquad
 K=R^{-1}B^TP,\quad u=-Kx.
\end{equation}
The optimal cost is $x(0)^TPx(0)$. These are infinite-horizon regulation
equations, not a finite-time reaching law with terminal accuracy constraints.
Tracking a target requires an appropriate equilibrium shift or augmented
model. The following checked solver exposes no unused noise parameter.

\begin{lstlisting}[language=Python, caption={Deterministic Continuous LQR With Explicit Preconditions.}]
from dataclasses import dataclass
import numpy as np
from scipy.linalg import solve_continuous_are


def finite_matrix(value: np.ndarray) -> np.ndarray:
    """Copy a nonempty finite matrix for a model boundary."""
    matrix = np.array(value, dtype=float, copy=True)
    if matrix.ndim != 2 or min(matrix.shape) == 0:
        raise ValueError("Expected a nonempty matrix")
    if not np.isfinite(matrix).all():
        raise ValueError("Matrix must be finite")
    return matrix


def check_weight(matrix: np.ndarray, size: int, strict: bool) -> None:
    """Require symmetric PSD cost, or PD input cost if strict."""
    if matrix.shape != (size, size):
        raise ValueError("Incorrect cost-matrix dimension")
    if not np.allclose(matrix, matrix.T, rtol=0, atol=1e-12):
        raise ValueError("Cost matrices must be symmetric")
    eigenvalues = np.linalg.eigvalsh(matrix)
    if np.any(eigenvalues < 0) or (strict and np.any(eigenvalues <= 0)):
        raise ValueError("Invalid cost definiteness")


def check_stabilizable(matrix: np.ndarray, inputs: np.ndarray) -> None:
    """PBH-test modes in the closed right half-plane, in floating point."""
    eigenvalues = np.linalg.eigvals(matrix)
    modes = eigenvalues[eigenvalues.real >= 0]
    if modes.size == 0:
        return
    size = matrix.shape[0]
    state_blocks = modes[:, None, None] * np.eye(size) - matrix
    input_blocks = np.broadcast_to(inputs, (len(modes), *inputs.shape))
    pbh = np.concatenate((state_blocks, input_blocks), axis=2)
    if np.any(np.linalg.matrix_rank(pbh) < size):
        raise ValueError("Unstable or neutral mode violates stabilizability")


@dataclass
class LQRProblem:
    """Full-state deterministic regulation with stabilizing CARE."""

    A: np.ndarray
    B: np.ndarray
    Q: np.ndarray
    R: np.ndarray

    def __post_init__(self) -> None:
        self.A = finite_matrix(self.A)
        self.B = finite_matrix(self.B)
        self.Q = finite_matrix(self.Q)
        self.R = finite_matrix(self.R)
        size = self.A.shape[0]
        if self.A.shape != (size, size) or self.B.shape[0] != size:
            raise ValueError("Incompatible dynamics dimensions")
        check_weight(self.Q, size, False)
        check_weight(self.R, self.B.shape[1], True)

    def solve(self) -> tuple[np.ndarray, np.ndarray]:
        """Return (K, P); ill-conditioned problems may be rejected."""
        check_stabilizable(self.A, self.B)
        # Symmetric PSD Q and its square root have the same range.
        check_stabilizable(self.A.T, self.Q)
        try:
            value = solve_continuous_are(self.A, self.B, self.Q, self.R)
            gain = np.linalg.solve(self.R, self.B.T @ value)
        except np.linalg.LinAlgError as error:
            raise ValueError("No reliable stabilizing CARE solution") from error
        return gain, value
\end{lstlisting}

The dual PBH test checks detectability, not full observability. Stable
unactuated or unobserved modes are allowed. Numerical rank and eigenvalue
tests are sensitive near singularity or the imaginary axis; this small
listing is not a certified solver for poorly scaled systems.

\subsection{A Zero Instantaneous Penalty Need Not Mean Irrelevance}

For the double integrator $\dot x_1=x_2$, $\dot x_2=u$, choose
$Q=\operatorname{diag}(1,0)$, $R=1$. Then
\begin{equation}
 P=\begin{pmatrix}\sqrt2&1\\1&\sqrt2\end{pmatrix},\qquad
 K=\begin{pmatrix}1&\sqrt2\end{pmatrix}.
\end{equation}
Velocity has zero direct running penalty but changes future position error,
so the controller feeds it back. By contrast, with
$A=\operatorname{diag}(-1,-2)$, $B=I$, the same $Q$ and $R=I$,
$K=P=\operatorname{diag}(\sqrt2-1,0)$: the second mode is stable, decoupled
and cost-free. These examples distinguish instantaneous output null space
from irrelevance to the entire future task.

Minimum intervention is a conditional consequence of the complete control
problem. Mechanical coupling, constraints, future contacts, observation
quality and noise can make a currently unpenalized deviation important.
Signal-dependent noise can change the tradeoff but is not the sole possible
reason to tolerate variability. In golf, a posture variation preserving the
current clubhead location may still alter future impact velocity or contact
feasibility.

\section{Additive and Command-Dependent Noise}

Consider a fully observed linear system with additive noise $D\,dW$.
For finite-horizon quadratic cost the value has form $V=x^TP(t)x+c(t)$.
The diffusion
contributes $\operatorname{tr}(PDD^T)$, independent of $u$, so the Riccati
gain is unchanged under these assumptions. Noise still changes covariance
and expected cost. Persistent noise with positive running cost generally
makes the undiscounted infinite total cost diverge. For a stable stationary
closed loop, the corresponding long-run average cost is
$\operatorname{tr}(PDD^T)$ under the standard integrability conditions.
This is a different criterion from the deterministic integral above.

For contrast, let
\begin{equation}
 dx=(ax+bu)\,dt+\sigma u\,dW,\qquad L=qx^2+ru^2.
\end{equation}
With value coefficient $p(t)$, the HJB terms depending on command are
$(r+\sigma^2p)u^2+2bpxu$. Thus, when the denominator is positive,
\begin{equation}
 u_*=-\frac{bp}{r+\sigma^2p}x,\qquad
 \dot p+2ap+q-\frac{b^2p^2}{r+\sigma^2p}=0.
\end{equation}
Here $\dot p=dp/dt$ uses forward time; the equation is solved backward
from the terminal cost coefficient $p(T)$. With $q\geq0$, $r>0$ and a
nonnegative terminal coefficient, the quadratic problem has nonnegative
$p$ and positive denominator on its finite solution interval.
Command-dependent noise
changes the gain; applying the deterministic CARE listing would solve a
different problem. If $u$ has state-per-time units, $\sigma$ here has
square-root-of-time units. Noise coefficients cannot be transferred between
discrete samples and continuous diffusions without specifying scaling.

Harris and Wolpert studied a particular minimum-variance formulation with
command-dependent noise~\cite{HarrisWolpert1998}. Their discrete model uses
$x_{k+1}=Ax_k+B(u_k+w_k)$ and $\operatorname{Var}(w_k)=k_nu_k^2$,
with a cost accumulating postmovement position variance. Neural command is
not automatically joint torque. Neither a universal human noise coefficient
nor a universal golf trajectory follows from that model.

\section{Minimum Jerk Is a Different Objective}

Flash and Hogan considered integrated squared hand jerk in planar arm
movements~\cite{FlashHogan1985}. For a scalar unconstrained displacement with
fixed duration $T$ and zero endpoint velocity and acceleration, minimizing
$\int_0^T(\dddot x)^2dt$ gives
\begin{equation}
 x(t)=x_0+(x_T-x_0)(10s^3-15s^4+6s^5),\qquad s=t/T.
\end{equation}
The Euler--Poisson condition is $x^{(6)}=0$; six endpoint conditions determine
the polynomial. Strict convexity in jerk, together with those conditions,
establishes the unique minimizer. Its speed is proportional to
$30s^2(1-s)^2$, with maximum $15|x_T-x_0|/(8T)$ at $s=1/2$.
This derivation is kinematic: it includes neither muscle energetics nor
signal-dependent noise. A minimum-variance model may produce similar shapes
under particular dynamics, but it is not generally equivalent to minimizing
jerk. Similar mean profiles require other experiments to distinguish objectives.

\section{Active Inference Needs an Action Model}

For a fixed observation $y$ and normalized approximate posterior $q(x)$,
\begin{align}
 F[q;y]&=\mathbb E_q[\log q(x)-\log p(x,y)]\\
       &=D_{\rm KL}\bigl(q(x)\,\|\,p(x\mid y)\bigr)-\log p(y).
 \label{eq:ch10:free-energy}
\end{align}
This identity requires compatible probability densities and finite relevant
integrals. Minimizing over $q$ at fixed $y$ performs inference. The expression
contains no action-to-observation dynamics by itself, so it does not specify
a command law. Free energy here is an information-theoretic quantity, not
mechanical energy in joules.

Friston and colleagues supply a particular extension coupling action and
inference~\cite{FristonAction2010Review}. Under their stated approximations,
action changes sensory signals and a gradient update reduces the resulting
precision-weighted prediction error. The proposal includes priors,
generative dynamics and sensory mappings; its simulations do not establish
that all motor circuits use this rule. Other active-inference formulations
may use explicit future policy objectives and information terms.

To compare such a model with optimal control, declare the same plant,
observations, constraints, prior preferences and task conditions. Compare
predictions and perturbation responses rather than equating the word
``error'' across objectives. This links prediction, mechanics and feedback
without treating their mathematical compatibility as biological proof.

\section*{Exercises}
\begin{enumerate}
 \item \textbf{Future Relevance.} Verify both LQR examples and explain
 why a zero velocity penalty does not imply zero velocity feedback.
 \item \textbf{Noise and Cost.} Derive the scalar command-noise Riccati
 equation. Contrast a finite-horizon expected cost with stationary average
 cost under additive noise; specify units and terminal conditions.
 \item \textbf{Trajectory Objectives.} Verify all six minimum-jerk
 endpoint conditions and the speed maximum. Choose a fully specified
 minimum-variance model and test whether its trajectory coincides; do not
 assume equivalence from a bell-shaped plot.
 \item \textbf{Inference and Action.} Derive the free-energy identity.
 State what additional model and objective would select an action, and what
 empirical observations could distinguish it from a competing controller.
\end{enumerate}
