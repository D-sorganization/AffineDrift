Contraction Theory Meets Tangent Spaces: Unifying Stability and Optimality

\renewcommand*\contentsname{Table of contents} { \hypersetup{linkcolor=} \setcounter{tocdepth}{3} \tableofcontents }

\section*{Abstract} \addcontentsline{toc}{section}{Abstract}

This article establishes a profound connection between two seemingly disparate frameworks in nonlinear control: contraction theory (Lohmiller \& Slotine, 1998) and tangent space methods for trajectory optimization. We prove that contraction metrics and optimal feedback gains are dual manifestations of the same geometric structure---the Riemannian metric on state space that governs both exponential stability and optimality. This unification reveals:

    \def\labelenumi{\arabic{enumi}.} \tightlist

  1. Stability ↔ Optimality Duality: Contraction metrics arise naturally as solutions to optimal control problems, while LQR gains induce contraction.
  2. Geometric Unification: Both frameworks operate on tangent spaces, with infinitesimal dynamics governed by the same differential Riccati equation.
  3. Design Synthesis: A new class of algorithms that simultaneously optimize trajectories while guaranteeing exponential stability through contraction constraints.

We demonstrate applications in biomechanics (muscle synergy stability), robotics (certified manipulation), and provide complete JAX implementations for computing contraction metrics via autodifferentiation.

Keywords: Contraction theory, differential dynamic programming, Riemannian geometry, exponential stability, optimal control, tangent spaces

Part I: Foundations

Contraction Theory Primer

The Essence of Contraction

Contraction theory provides a coordinate-free framework for establishing exponential stability of nonlinear dynamical systems. Unlike Lyapunov theory, which focuses on distance in state space, contraction analyzes how infinitesimal perturbations evolve.

Core Definition

Consider a dynamical system:

\[\phantomsection{ \dot{\mathbf{x}} = \mathbf{f}(\mathbf{x}, t) }\]

The system is contracting if the distance between neighboring trajectories decreases exponentially.

\begin{tcolorbox}[enhanced jigsaw, left=2mm, coltitle=black, breakable, title={Definition 1.1 (Contraction)}, toprule=.15mm, titlerule=0mm, leftrule=.75mm, colframe=quarto-callout-note-color-frame, arc=.35mm, colback=white, opacityback=0, toptitle=1mm, colbacktitle=quarto-callout-note-color!10!white, rightrule=.15mm, bottomrule=.15mm, opacitybacktitle=0.6, bottomtitle=1mm]

System (Equation~eq-dynamics) is contracting in a region \(\mathcal{D} \subset \mathbb{R}^n\) with rate \(\lambda > 0\) if there exists a uniformly positive definite metric \(\mathbf{M}(\mathbf{x}, t) = \mathbf{\Theta}^\top(\mathbf{x}, t) \mathbf{\Theta}(\mathbf{x}, t)\) such that:

\[\phantomsection{ \frac{\partial \mathbf{F}}{\partial \mathbf{x}} + \frac{\partial \mathbf{F}^\top}{\partial \mathbf{x}} \prec -2\lambda \mathbf{I} }\]
where \(\mathbf{F} = \mathbf{\Theta}^{-1} \mathbf{f}\) is the dynamics in transformed coordinates \(\delta \mathbf{z} = \mathbf{\Theta} \, \delta \mathbf{x}\).

\end{tcolorbox}

Physical Interpretation: Virtual displacements \(\delta \mathbf{x}\) evolve according to:

\[\phantomsection{ \frac{d}{dt}(\delta \mathbf{x}) = \frac{\partial \mathbf{f}}{\partial \mathbf{x}} \delta \mathbf{x} }\]

If the system is contracting, any two trajectories converge exponentially:

\[\phantomsection{ \|\delta \mathbf{x}(t)\|_{\mathbf{M}} \leq \|\delta \mathbf{x}(0)\|_{\mathbf{M}} e^{-\lambda t} }\]

Connection to Riemannian Geometry

The metric \(\mathbf{M}(\mathbf{x})\) defines a Riemannian structure on state space. The squared length of an infinitesimal displacement is:

\[\phantomsection{ ds^2 = \delta \mathbf{x}^\top \mathbf{M}(\mathbf{x}) \, \delta \mathbf{x} }\]

Contraction asks: Does the flow shrink volumes in this metric?

The generalized Jacobian in metric coordinates is:

\[\phantomsection{ \mathbf{J}_{\mathbf{M}} = \mathbf{M}^{-1/2} \left( \frac{\partial \mathbf{f}}{\partial \mathbf{x}} \mathbf{M} + \mathbf{M} \frac{\partial \mathbf{f}^\top}{\partial \mathbf{x}} + \dot{\mathbf{M}} \right) \mathbf{M}^{-1/2} }\]

Contraction requires:

\[\phantomsection{ \lambda_{\max}(\mathbf{J}_{\mathbf{M}}) < -\lambda }\]

Fundamental Theorems

\begin{tcolorbox}[enhanced jigsaw, left=2mm, coltitle=black, breakable, title={Theorem 1.1 (Lohmiller-Slotine)}, toprule=.15mm, titlerule=0mm, leftrule=.75mm, colframe=quarto-callout-important-color-frame, arc=.35mm, colback=white, opacityback=0, toptitle=1mm, colbacktitle=quarto-callout-important-color!10!white, rightrule=.15mm, bottomrule=.15mm, opacitybacktitle=0.6, bottomtitle=1mm]

If system (Equation~eq-dynamics) is contracting, then:

    \def\labelenumi{\arabic{enumi}.} \tightlist

  1. Uniqueness: All trajectories converge to a single trajectory (steady state, periodic orbit, or any solution).
  2. Exponential Convergence: Rate is bounded by the contraction rate \(\lambda\).
  3. Robustness: Convergence is preserved under perturbations bounded in the metric \(\mathbf{M}\).

\end{tcolorbox}

Proof Sketch: Consider two trajectories \(\mathbf{x}_1(t)\), \(\mathbf{x}_2(t)\) with infinitesimal separation \(\delta \mathbf{x} = \mathbf{x}_2 - \mathbf{x}_1\). Define the squared distance:

\[\phantomsection{ V = \delta \mathbf{x}^\top \mathbf{M} \, \delta \mathbf{x} }\]

Time derivative:

\[\phantomsection{ \begin{aligned} \dot{V} &= \delta \mathbf{x}^\top \left( \mathbf{M} \frac{\partial \mathbf{f}}{\partial \mathbf{x}} + \frac{\partial \mathbf{f}^\top}{\partial \mathbf{x}} \mathbf{M} + \dot{\mathbf{M}} \right) \delta \mathbf{x} \\ &\leq -2\lambda V \end{aligned} }\]

by the contraction condition. Integration yields (Equation~eq-exponential-convergence). \(\square\)

Example: Linear Systems

For \(\dot{\mathbf{x}} = \mathbf{A} \mathbf{x}\), contraction is equivalent to:

\[\phantomsection{ \exists \mathbf{M} \succ 0: \quad \mathbf{A}^\top \mathbf{M} + \mathbf{M} \mathbf{A} \prec -2\lambda \mathbf{M} }\]

This is a Lyapunov inequality. If \(\mathbf{A}\) is Hurwitz (stable), we can find such \(\mathbf{M}\) by solving:

\[\phantomsection{ \mathbf{A}^\top \mathbf{M} + \mathbf{M} \mathbf{A} = -\mathbf{Q} }\]
for any \(\mathbf{Q} \succ 0\).

Key Insight: For linear systems, any Lyapunov function yields a contraction metric. This extends to nonlinear systems via local linearization---a connection we'll exploit later.

Hierarchical Combination Theorems

One of contraction theory's most powerful features is compositionality: Contracting subsystems combine to form contracting systems.

\begin{tcolorbox}[enhanced jigsaw, left=2mm, coltitle=black, breakable, title={Theorem 1.2 (Parallel Combination)}, toprule=.15mm, titlerule=0mm, leftrule=.75mm, colframe=quarto-callout-note-color-frame, arc=.35mm, colback=white, opacityback=0, toptitle=1mm, colbacktitle=quarto-callout-note-color!10!white, rightrule=.15mm, bottomrule=.15mm, opacitybacktitle=0.6, bottomtitle=1mm]

If \(\dot{\mathbf{x}}_1 = \mathbf{f}_1(\mathbf{x}_1, \mathbf{u})\) and \(\dot{\mathbf{x}}_2 = \mathbf{f}_2(\mathbf{x}_2, \mathbf{u})\) are both contracting w.r.t. \(\mathbf{u}\), then:

\[\phantomsection{ \begin{bmatrix} \dot{\mathbf{x}}_1 \\ \dot{\mathbf{x}}_2 \end{bmatrix} = \begin{bmatrix} \mathbf{f}_1(\mathbf{x}_1, \mathbf{u}) \\ \mathbf{f}_2(\mathbf{x}_2, \mathbf{u}) \end{bmatrix} }\]
is contracting w.r.t. \(\mathbf{u}\).

\end{tcolorbox}

Application: Modular robot control---if each joint controller is contracting, the full system is contracting.

Tangent Spaces and Variational Dynamics

Review from Unified Thesis

In the tangent space framework, we consider a nominal trajectory \(\mathbf{x}^*_t\) and analyze perturbed trajectories \(\mathbf{x}_t = \mathbf{x}^*_t + \delta \mathbf{x}_t\) in the tangent bundle \(T\mathcal{M}\).

The δ-Dynamics

Perturbed trajectories satisfy:

\[\phantomsection{ \mathbf{x}_{t+1} = \mathbf{x}^*_{t+1} + \mathbf{A}_t \delta \mathbf{x}_t + \mathbf{B}_t \delta \mathbf{u}_t + O(\|\delta\|^2) }\]

where:

\[\phantomsection{ \begin{aligned} \mathbf{A}_t &= \frac{\partial \mathbf{f}}{\partial \mathbf{x}}\bigg|_{(\mathbf{x}^*_t, \mathbf{u}^*_t)} \\ \mathbf{B}_t &= \frac{\partial \mathbf{f}}{\partial \mathbf{u}}\bigg|_{(\mathbf{x}^*_t, \mathbf{u}^*_t)} \end{aligned} }\]

For continuous-time systems:

\[\phantomsection{ \delta \dot{\mathbf{x}} = \mathbf{A}(t) \, \delta \mathbf{x} + \mathbf{B}(t) \, \delta \mathbf{u} }\]

This is precisely the virtual displacement equation (Equation~eq-virtual-displacement) from contraction theory!

Variational Principles

The tangent dynamics arise from the variational principle:

\[\phantomsection{ \delta \int_0^T L(\mathbf{x}, \mathbf{u}) \, dt = 0 }\]

This yields the Euler-Lagrange equations:

\[\phantomsection{ \frac{\partial L}{\partial \mathbf{x}} - \frac{d}{dt} \frac{\partial L}{\partial \dot{\mathbf{x}}} = 0 }\]

Taking variations:

\[\phantomsection{ \delta^2 L = \delta \mathbf{x}^\top \mathbf{Q}_t \, \delta \mathbf{x} + \delta \mathbf{u}^\top \mathbf{R}_t \, \delta \mathbf{u} }\]

where \(\mathbf{Q}_t = \frac{\partial^2 L}{\partial \mathbf{x}^2}\), \(\mathbf{R}_t = \frac{\partial^2 L}{\partial \mathbf{u}^2}\).

Differential Dynamic Programming

DDP exploits the tangent space structure by solving a sequence of time-varying LQR problems:

\[\phantomsection{ \min_{\delta \mathbf{u}} \frac{1}{2} \delta \mathbf{x}_T^\top \mathbf{Q}_T \delta \mathbf{x}_T + \frac{1}{2} \sum_{t=0}^{T-1} \left( \delta \mathbf{x}_t^\top \mathbf{Q}_t \delta \mathbf{x}_t + \delta \mathbf{u}_t^\top \mathbf{R}_t \delta \mathbf{u}_t \right) }\]

subject to (Equation~eq-discrete-tangent).

The solution is:

\[\phantomsection{ \delta \mathbf{u}_t = -\mathbf{K}_t \delta \mathbf{x}_t }\]

where \(\mathbf{K}_t\) satisfies the discrete-time Riccati recursion:

\[\phantomsection{ \begin{aligned} \mathbf{S}_T &= \mathbf{Q}_T \\ \mathbf{K}_t &= (\mathbf{R}_t + \mathbf{B}_t^\top \mathbf{S}_{t+1} \mathbf{B}_t)^{-1} \mathbf{B}_t^\top \mathbf{S}_{t+1} \mathbf{A}_t \\ \mathbf{S}_t &= \mathbf{Q}_t + \mathbf{A}_t^\top \mathbf{S}_{t+1} (\mathbf{A}_t - \mathbf{B}_t \mathbf{K}_t) \end{aligned} }\]

Key Observation: \(\mathbf{S}_t\) is a time-varying metric that measures the cost-to-go from state \(\mathbf{x}_t\).

Connection to Virtual Displacements

In classical mechanics, virtual displacements \(\delta \mathbf{x}\) satisfy:

\[\phantomsection{ \delta W = \mathbf{F} \cdot \delta \mathbf{x} = 0 }\]

where \(\mathbf{F}\) are constraint forces. The tangent space \(T_{\mathbf{x}} \mathcal{M}\) contains all admissible displacements.

Analogy: - Mechanical constraints \(\leftrightarrow\) Dynamics \(\dot{\mathbf{x}} = \mathbf{f}(\mathbf{x}, \mathbf{u})\) - Virtual displacements \(\leftrightarrow\) State perturbations \(\delta \mathbf{x}\) - D'Alembert's principle \(\leftrightarrow\) Optimality conditions

This suggests a deep connection between variational mechanics and contraction theory.

The Duality Revealed

Exponential Forgetting vs.~Exponential Convergence

Contraction Perspective

Contraction theory states: Perturbations decay exponentially in the metric \(\mathbf{M\)}:

\[\phantomsection{ \|\delta \mathbf{x}(t)\|_{\mathbf{M}}^2 = \delta \mathbf{x}^\top \mathbf{M} \, \delta \mathbf{x} \leq e^{-2\lambda t} \|\delta \mathbf{x}(0)\|_{\mathbf{M}}^2 }\]

Optimality Perspective

LQR theory states: Deviations from optimal trajectory incur cost growing quadratically:

\[\phantomsection{ V(\delta \mathbf{x}_t) = \delta \mathbf{x}_t^\top \mathbf{S}_t \delta \mathbf{x}_t }\]

The closed-loop system:

\[\phantomsection{ \delta \mathbf{x}_{t+1} = (\mathbf{A}_t - \mathbf{B}_t \mathbf{K}_t) \delta \mathbf{x}_t }\]

is exponentially stable if \(\rho(\mathbf{A}_t - \mathbf{B}_t \mathbf{K}_t) < 1\).

The Duality

Claim: The Riccati solution \(\mathbf{S}_t\) is a contraction metric!

\begin{tcolorbox}[enhanced jigsaw, left=2mm, coltitle=black, breakable, title={Theorem 3.1 (Stability-Optimality Duality)}, toprule=.15mm, titlerule=0mm, leftrule=.75mm, colframe=quarto-callout-important-color-frame, arc=.35mm, colback=white, opacityback=0, toptitle=1mm, colbacktitle=quarto-callout-important-color!10!white, rightrule=.15mm, bottomrule=.15mm, opacitybacktitle=0.6, bottomtitle=1mm]

Consider the LQR problem (Equation~eq-lqr-subproblem) with solution \(\mathbf{K}_t\), \(\mathbf{S}_t\). Then:

    \def\labelenumi{\arabic{enumi}.} \tightlist

  1. \(\mathbf{S}_t \succ 0\) defines a Riemannian metric on tangent space.
  2. The closed-loop system (Equation~eq-closed-loop) is contracting w.r.t. metric \(\mathbf{M}_t = \mathbf{S}_t\).
  3. The contraction rate is \(\lambda = -\frac{1}{2} \log \rho(\mathbf{A}_t - \mathbf{B}_t \mathbf{K}_t)\).

\end{tcolorbox}

Proof: Define the Lyapunov function \(V_t = \delta \mathbf{x}_t^\top \mathbf{S}_t \delta \mathbf{x}_t\). Then:

\[\phantomsection{ \begin{aligned} V_{t+1} &= \delta \mathbf{x}_{t+1}^\top \mathbf{S}_{t+1} \delta \mathbf{x}_{t+1} \\ &= \delta \mathbf{x}_t^\top (\mathbf{A}_t - \mathbf{B}_t \mathbf{K}_t)^\top \mathbf{S}_{t+1} (\mathbf{A}_t - \mathbf{B}_t \mathbf{K}_t) \delta \mathbf{x}_t \end{aligned} }\]

By the Riccati equation (Equation~eq-discrete-riccati):

\[\phantomsection{ (\mathbf{A}_t - \mathbf{B}_t \mathbf{K}_t)^\top \mathbf{S}_{t+1} (\mathbf{A}_t - \mathbf{B}_t \mathbf{K}_t) = \mathbf{S}_t - \mathbf{Q}_t - \mathbf{K}_t^\top \mathbf{R}_t \mathbf{K}_t }\]

Thus:

\[\phantomsection{ V_{t+1} = V_t - \delta \mathbf{x}_t^\top (\mathbf{Q}_t + \mathbf{K}_t^\top \mathbf{R}_t \mathbf{K}_t) \delta \mathbf{x}_t }\]

Since \(\mathbf{Q}_t, \mathbf{R}_t \succ 0\):

\[\phantomsection{ V_{t+1} \leq \rho V_t }\]

where \(\rho = 1 - \frac{\lambda_{\min}(\mathbf{Q}_t)}{\lambda_{\max}(\mathbf{S}_t)} < 1\). This is exactly the discrete-time contraction condition. \(\square\)

Continuous-Time Riccati Connection

For continuous systems, the differential Riccati equation (DRE) is:

\[\phantomsection{ -\dot{\mathbf{S}} = \mathbf{A}^\top \mathbf{S} + \mathbf{S} \mathbf{A} - \mathbf{S} \mathbf{B} \mathbf{R}^{-1} \mathbf{B}^\top \mathbf{S} + \mathbf{Q} }\]

Compare with the contraction condition (Equation~eq-linear-contraction):

\[\phantomsection{ \mathbf{A}^\top \mathbf{M} + \mathbf{M} \mathbf{A} = -\mathbf{Q} - \mathbf{M} \mathbf{B} \mathbf{R}^{-1} \mathbf{B}^\top \mathbf{M} }\]

These are identical when \(\mathbf{M}\) is constant (\(\dot{\mathbf{M}} = 0\)) and we set \(\mathbf{M} = \mathbf{S}\).

Infinite-Horizon Case

For the infinite-horizon problem:

\[\phantomsection{ \min_{\mathbf{u}} \int_0^\infty \left( \mathbf{x}^\top \mathbf{Q} \mathbf{x} + \mathbf{u}^\top \mathbf{R} \mathbf{u} \right) dt }\]

The algebraic Riccati equation (ARE) is:

\[\phantomsection{ \mathbf{A}^\top \mathbf{S} + \mathbf{S} \mathbf{A} - \mathbf{S} \mathbf{B} \mathbf{R}^{-1} \mathbf{B}^\top \mathbf{S} + \mathbf{Q} = 0 }\]

This is precisely the steady-state contraction metric!

\begin{tcolorbox}[enhanced jigsaw, left=2mm, coltitle=black, breakable, title={Corollary 3.1 (LQR Induces Contraction)}, toprule=.15mm, titlerule=0mm, leftrule=.75mm, colframe=quarto-callout-note-color-frame, arc=.35mm, colback=white, opacityback=0, toptitle=1mm, colbacktitle=quarto-callout-note-color!10!white, rightrule=.15mm, bottomrule=.15mm, opacitybacktitle=0.6, bottomtitle=1mm]

The LQR controller \(\mathbf{u} = -\mathbf{K} \mathbf{x}\) where \(\mathbf{K} = \mathbf{R}^{-1} \mathbf{B}^\top \mathbf{S}\) renders the closed-loop system:

\[\phantomsection{ \dot{\mathbf{x}} = (\mathbf{A} - \mathbf{B} \mathbf{K}) \mathbf{x} }\]
contracting with metric \(\mathbf{M} = \mathbf{S}\) and rate \(\lambda = \frac{1}{2} \lambda_{\min}(\mathbf{S} \mathbf{B} \mathbf{R}^{-1} \mathbf{B}^\top \mathbf{S})\).

\end{tcolorbox}

Interpretation: Optimal control automatically ensures exponential stability through the induced contraction metric!

Geometric Interpretation

Riemannian Curvature

The metric \(\mathbf{S}_t\) defines a curved geometry on state space. The Riemann curvature tensor captures how geodesics (optimal trajectories) diverge.

For a flat metric (\(\mathbf{M} = \mathbf{I}\)), geodesics are straight lines. The Riccati metric curves space such that all geodesics converge to the optimal trajectory.

Geodesic Equation

In Riemannian geometry, the geodesic equation is:

\[\phantomsection{ \ddot{\mathbf{x}}^i + \Gamma^i_{jk} \dot{\mathbf{x}}^j \dot{\mathbf{x}}^k = 0 }\]

where \(\Gamma^i_{jk}\) are Christoffel symbols:

\[\phantomsection{ \Gamma^i_{jk} = \frac{1}{2} g^{il} \left( \frac{\partial g_{lj}}{\partial x^k} + \frac{\partial g_{lk}}{\partial x^j} - \frac{\partial g_{jk}}{\partial x^l} \right) }\]

with \(g_{ij} = (\mathbf{M})_{ij}\) the metric components.

Connection: The optimal feedback law \(\mathbf{u} = -\mathbf{K} \mathbf{x}\) can be viewed as a geodesic spray that forces trajectories onto optimal geodesics.

Part II: Theory

Contraction-Constrained DDP

Motivation: Stability Guarantees from Optimization

Standard DDP provides local stability around the nominal trajectory but no guarantees about: - Basin of attraction size - Convergence rate - Robustness to disturbances

Idea: Augment the cost function with a contraction penalty:

\[\phantomsection{ J = \phi(\mathbf{x}_T) + \int_0^T \left[ L(\mathbf{x}, \mathbf{u}) + \mu \, \mathcal{C}(\mathbf{x}, \mathbf{u}) \right] dt }\]

where \(\mathcal{C}(\mathbf{x}, \mathbf{u})\) measures deviation from contraction.

Contraction Metric as Soft Constraint

Define the contraction defect:

\[\phantomsection{ \mathcal{C}(\mathbf{x}, \mathbf{u}) = \lambda_{\max}\left( \frac{\partial \mathbf{f}}{\partial \mathbf{x}} \mathbf{M} + \mathbf{M} \frac{\partial \mathbf{f}^\top}{\partial \mathbf{x}} + \dot{\mathbf{M}} \right) }\]

For a contracting system, \(\mathcal{C} < -2\lambda \lambda_{\min}(\mathbf{M})\).

Penalty formulation:

\[\phantomsection{ \mathcal{C}_{\text{penalty}}(\mathbf{x}, \mathbf{u}) = \max(0, \mathcal{C}(\mathbf{x}, \mathbf{u}) + 2\lambda \lambda_{\min}(\mathbf{M}))^2 }\]

This is zero when contracting, positive otherwise.

Algorithm: Contraction-DDP

Input: Initial trajectory \(\{\mathbf{x}^*_t, \mathbf{u}^*_t\}\), desired contraction rate \(\lambda\), penalty weight \(\mu\)

Repeat until convergence:

    \def\labelenumi{\arabic{enumi}.}

  1. Forward Pass: Simulate dynamics, compute costs.
  2. Metric Update: For each \(t\), solve for optimal metric \(\mathbf{M}_t\) via:
    \[\phantomsection{ \min_{\mathbf{M}_t \succ 0} \, \text{tr}(\mathbf{M}_t) + \mu \, \mathcal{C}_{\text{penalty}}(\mathbf{x}^*_t, \mathbf{u}^*_t; \mathbf{M}_t) }\]

    Convex optimization (SDP) in \(\mathbf{M}_t\).

  3. Backward Pass: Compute Riccati recursion with augmented cost:
    \[\phantomsection{ \begin{aligned} \tilde{\mathbf{Q}}_t &= \mathbf{Q}_t + \mu \frac{\partial \mathcal{C}}{\partial \mathbf{x}} \\ \tilde{\mathbf{R}}_t &= \mathbf{R}_t + \mu \frac{\partial \mathcal{C}}{\partial \mathbf{u}} \end{aligned} }\]

    Use \(\tilde{\mathbf{Q}}_t\), \(\tilde{\mathbf{R}}_t\) in (Equation~eq-discrete-riccati).

  4. Line Search: Update trajectory with step size \(\alpha\).

Output: Trajectory \(\{\mathbf{x}^*_t, \mathbf{u}^*_t\}\) with certified contraction rate \(\lambda\).

Stability Guarantees

\begin{tcolorbox}[enhanced jigsaw, left=2mm, coltitle=black, breakable, title={Theorem 4.1 (Certified Stability from Contraction-DDP)}, toprule=.15mm, titlerule=0mm, leftrule=.75mm, colframe=quarto-callout-important-color-frame, arc=.35mm, colback=white, opacityback=0, toptitle=1mm, colbacktitle=quarto-callout-important-color!10!white, rightrule=.15mm, bottomrule=.15mm, opacitybacktitle=0.6, bottomtitle=1mm]

Let \(\{\mathbf{x}^*_t, \mathbf{u}^*_t, \mathbf{M}_t\}\) be the output of Contraction-DDP with penalty weight \(\mu\) sufficiently large. Then:

    \def\labelenumi{\arabic{enumi}.} \tightlist

  1. The closed-loop system \(\dot{\mathbf{x}} = \mathbf{f}(\mathbf{x}, \mathbf{u}^*_t - \mathbf{K}_t(\mathbf{x} - \mathbf{x}^*_t))\) is contracting with rate \(\lambda\).
  2. The basin of attraction contains all \(\mathbf{x}_0\) with \(\|\mathbf{x}_0 - \mathbf{x}^*_0\|_{\mathbf{M}_0} < \epsilon\) where \(\epsilon\) is determined by linearization validity.
  3. Convergence is exponential: \(\|\mathbf{x}_t - \mathbf{x}^*_t\|_{\mathbf{M}_t} \leq e^{-\lambda t} \|\mathbf{x}_0 - \mathbf{x}^*_0\|_{\mathbf{M}_0}\).

\end{tcolorbox}

Proof Sketch: The penalty forces \(\mathcal{C}(\mathbf{x}^*_t, \mathbf{u}^*_t) \to 0\) as \(\mu \to \infty\). By continuity, there exists a neighborhood where (Equation~eq-contraction-condition) holds. \(\square\)

LQR as Contraction Design

Algebraic vs.~Differential Riccati

Time-Varying Case (Finite Horizon)

The DRE (Equation~eq-differential-riccati) describes how the value function propagates backward in time:

\[\phantomsection{ -\dot{\mathbf{S}} = \mathbf{Q} + \mathbf{A}^\top \mathbf{S} + \mathbf{S} \mathbf{A} - \mathbf{S} \mathbf{B} \mathbf{R}^{-1} \mathbf{B}^\top \mathbf{S} }\]

with terminal condition \(\mathbf{S}(T) = \mathbf{Q}_T\).

Contraction interpretation: \(\mathbf{S}(t)\) is the time-varying metric that makes the closed-loop maximally contracting at each instant.

Time-Invariant Case (Infinite Horizon)

Setting \(\dot{\mathbf{S}} = 0\) yields the ARE (Equation~eq-algebraic-riccati). The solution \(\mathbf{S}_\infty\) is the unique positive-definite stabilizing solution.

\begin{tcolorbox}[enhanced jigsaw, left=2mm, coltitle=black, breakable, title={Proposition 5.1 (ARE as Contraction Design)}, toprule=.15mm, titlerule=0mm, leftrule=.75mm, colframe=quarto-callout-note-color-frame, arc=.35mm, colback=white, opacityback=0, toptitle=1mm, colbacktitle=quarto-callout-note-color!10!white, rightrule=.15mm, bottomrule=.15mm, opacitybacktitle=0.6, bottomtitle=1mm]

For a controllable pair \((\mathbf{A}, \mathbf{B})\), the ARE solution \(\mathbf{S}_\infty\) is the minimal metric (in Loewner order) such that:

\[\phantomsection{ \mathbf{A}^\top \mathbf{S}_\infty + \mathbf{S}_\infty \mathbf{A} - \mathbf{S}_\infty \mathbf{B} \mathbf{R}^{-1} \mathbf{B}^\top \mathbf{S}_\infty + \mathbf{Q} = 0 }\]

guarantees contraction with the fastest possible rate given control cost \(\mathbf{R}\).

\end{tcolorbox}

Proof: The rate of contraction is determined by the most negative eigenvalue of:

\[\phantomsection{ (\mathbf{A} - \mathbf{B} \mathbf{K})^\top \mathbf{S}_\infty + \mathbf{S}_\infty (\mathbf{A} - \mathbf{B} \mathbf{K}) = -\mathbf{Q} - \mathbf{K}^\top \mathbf{R} \mathbf{K} }\]

Maximizing this requires minimizing \(\text{tr}(\mathbf{K}^\top \mathbf{R} \mathbf{K})\) subject to stability---exactly the LQR problem. \(\square\)

Design Procedure: Specifying Contraction Rate

Problem: Given desired contraction rate \(\lambda\), find \(\mathbf{Q}\), \(\mathbf{R}\) such that the LQR solution achieves this rate.

Solution: Solve the inverse LQR problem.

Method 1: Eigenvalue Placement

The closed-loop eigenvalues are \(\text{eig}(\mathbf{A} - \mathbf{B} \mathbf{K})\). We want:

\[\phantomsection{ \text{Re}(\lambda_i) \leq -\lambda \quad \forall i }\]

This is achieved by choosing:

\[\phantomsection{ \mathbf{Q} = \alpha \mathbf{I}, \quad \mathbf{R} = \beta \mathbf{I} }\]

and adjusting \(\alpha/\beta\) ratio. Larger \(\alpha/\beta\) → faster convergence (higher \(\lambda\)).

Method 2: Contraction Rate Constraint

Directly enforce:

\[\phantomsection{ (\mathbf{A} - \mathbf{B} \mathbf{K})^\top \mathbf{S} + \mathbf{S} (\mathbf{A} - \mathbf{B} \mathbf{K}) \preceq -2\lambda \mathbf{S} }\]

This is a bilinear matrix inequality (BMI) in \(\mathbf{K}\), \(\mathbf{S}\).

Convex relaxation: Fix \(\mathbf{K}\), solve for \(\mathbf{S}\) (convex). Then fix \(\mathbf{S}\), solve for \(\mathbf{K}\) (convex). Alternate until convergence.

Optimal gain:

\[\phantomsection{ \mathbf{K} = \begin{bmatrix} 2.000 & 2.000 \end{bmatrix} }\]

Closed-loop eigenvalues: \(\{-1.0 \pm j\}\), implying \(\lambda_{\min} = 1.0\).

To increase \(\lambda\): Increase \(\mathbf{Q}/\mathbf{R}\) ratio. E.g., \(\mathbf{Q} = \text{diag}(64, 4)\) yields \(\lambda = 2.0\).

Coordinate-Free Formulation

Differential Geometry Perspective

Tangent Bundle Formulation

The state space \(\mathcal{M}\) is a smooth manifold (e.g., configuration space). The tangent bundle \(T\mathcal{M}\) consists of pairs \((\mathbf{x}, \delta \mathbf{x})\) where: - \(\mathbf{x} \in \mathcal{M}\) (base point) - \(\delta \mathbf{x} \in T_{\mathbf{x}} \mathcal{M}\) (tangent vector)

Dynamics lift to \(T\mathcal{M}\):

\[\phantomsection{ \begin{aligned} \dot{\mathbf{x}} &= \mathbf{f}(\mathbf{x}, \mathbf{u}) \\ \frac{D}{dt} \delta \mathbf{x} &= \frac{\partial \mathbf{f}}{\partial \mathbf{x}} \delta \mathbf{x} + \frac{\partial \mathbf{f}}{\partial \mathbf{u}} \delta \mathbf{u} \end{aligned} }\]

where \(\frac{D}{dt}\) is the covariant derivative along the flow.

Riemannian Metric Tensor

A metric \(g: T\mathcal{M} \times T\mathcal{M} \to \mathbb{R}\) assigns an inner product to each tangent space:

\[\phantomsection{ g_{\mathbf{x}}(\delta \mathbf{x}_1, \delta \mathbf{x}_2) = \delta \mathbf{x}_1^\top \mathbf{M}(\mathbf{x}) \delta \mathbf{x}_2 }\]

In coordinates \(\{x^i\}\):

\[\phantomsection{ ds^2 = g_{ij} dx^i dx^j }\]

Pullback Metrics and Natural Coordinates

Configuration Space vs.~Task Space

Consider a robot with configuration \(\mathbf{q} \in \mathbb{R}^n\) and end-effector position \(\mathbf{x} = \mathbf{h}(\mathbf{q}) \in \mathbb{R}^m\).

The task-space metric:

\[\phantomsection{ \mathbf{M}_{\mathbf{x}} = \mathbf{I}_m }\]

Pullback to configuration space:

\[\phantomsection{ \mathbf{M}_{\mathbf{q}} = \mathbf{J}^\top(\mathbf{q}) \mathbf{M}_{\mathbf{x}} \mathbf{J}(\mathbf{q}) }\]

where \(\mathbf{J} = \frac{\partial \mathbf{h}}{\partial \mathbf{q}}\) is the Jacobian.

Physical meaning: Distances in \(\mathbf{q}\)-space are weighted by how much they affect \(\mathbf{x}\)-space (task-relevant).

Example: Planar Arm

Configuration: \(\mathbf{q} = [\theta_1, \theta_2]^\top\) (joint angles).

End-effector position:

\[\phantomsection{ \mathbf{x} = \begin{bmatrix} l_1 \cos \theta_1 + l_2 \cos(\theta_1 + \theta_2) \\ l_1 \sin \theta_1 + l_2 \sin(\theta_1 + \theta_2) \end{bmatrix} }\]

Jacobian:

\[\phantomsection{ \mathbf{J} = \begin{bmatrix} -l_1 \sin \theta_1 - l_2 \sin(\theta_1 + \theta_2) & -l_2 \sin(\theta_1 + \theta_2) \\ l_1 \cos \theta_1 + l_2 \cos(\theta_1 + \theta_2) & l_2 \cos(\theta_1 + \theta_2) \end{bmatrix} }\]

Pullback metric:

\[\phantomsection{ \mathbf{M}_{\mathbf{q}} = \mathbf{J}^\top \mathbf{J} = \begin{bmatrix} l_1^2 + l_2^2 + 2 l_1 l_2 \cos \theta_2 & l_2^2 + l_1 l_2 \cos \theta_2 \\ l_2^2 + l_1 l_2 \cos \theta_2 & l_2^2 \end{bmatrix} }\]

This is the kinetic energy metric (mass matrix with unit link masses).

Gauge Freedom and Metric Choice

Equivalence Classes

Two metrics \(\mathbf{M}_1\), \(\mathbf{M}_2\) are gauge equivalent if there exists a diffeomorphism \(\phi: \mathcal{M} \to \mathcal{M}\) such that:

\[\phantomsection{ \mathbf{M}_2 = \phi^* \mathbf{M}_1 }\]

where \(\phi^*\) is the pullback.

Physical example: Changing coordinates \(\mathbf{x} \to \mathbf{z} = \boldsymbol{\phi}(\mathbf{x})\) induces:

\[\phantomsection{ \mathbf{M}_{\mathbf{z}} = \left( \frac{\partial \boldsymbol{\phi}}{\partial \mathbf{x}} \right)^\top \mathbf{M}_{\mathbf{x}} \left( \frac{\partial \boldsymbol{\phi}}{\partial \mathbf{x}} \right) }\]

Canonical Choices

Several natural metric choices:

    \def\labelenumi{\arabic{enumi}.}

  1. Euclidean: \(\mathbf{M} = \mathbf{I}\) (simplest, but coordinate-dependent).
  2. Fisher Information: \(\mathbf{M}_{ij} = \mathbb{E}\left[ \frac{\partial \log p}{\partial x^i} \frac{\partial \log p}{\partial x^j} \right]\) for probabilistic systems.
  3. Kinetic Energy: \(\mathbf{M} = \mathbf{D}(\mathbf{q})\) (inertia matrix) for mechanical systems.
  4. Control Metric: \(\mathbf{M} = \mathbf{B} \mathbf{R}^{-1} \mathbf{B}^\top\) (control authority).
  5. Riccati Metric: \(\mathbf{M} = \mathbf{S}\) (optimal control).

Trade-off: Simpler metrics (e.g., Euclidean) are easier to compute but may not respect system structure. Intrinsic metrics (e.g., kinetic energy) are more natural but computationally expensive.

Optimal Metric via Trace Minimization

Among all metrics satisfying the contraction condition, choose the one minimizing:

\[\phantomsection{ \min_{\mathbf{M} \succ 0} \, \text{tr}(\mathbf{M}) }\]

subject to:

\[\phantomsection{ \mathbf{A}^\top \mathbf{M} + \mathbf{M} \mathbf{A} + \dot{\mathbf{M}} \preceq -2\lambda \mathbf{M} }\]

This is a convex SDP (linear matrix inequality).

Interpretation: Smallest metric = largest basin of attraction.

Contraction-Based Task Space Control

Operational Space Formulation

Robot dynamics:

\[\phantomsection{ \mathbf{D}(\mathbf{q}) \ddot{\mathbf{q}} + \mathbf{C}(\mathbf{q}, \dot{\mathbf{q}}) \dot{\mathbf{q}} + \mathbf{g}(\mathbf{q}) = \boldsymbol{\tau} }\]

Task dynamics:

\[\phantomsection{ \mathbf{\Lambda}(\mathbf{x}) \ddot{\mathbf{x}} + \boldsymbol{\mu}(\mathbf{x}, \dot{\mathbf{x}}) \dot{\mathbf{x}} + \mathbf{p}(\mathbf{x}) = \mathbf{F} }\]

where:

\[\phantomsection{ \begin{aligned} \mathbf{\Lambda} &= (\mathbf{J} \mathbf{D}^{-1} \mathbf{J}^\top)^{-1} \\ \boldsymbol{\mu} &= \mathbf{\Lambda} (\dot{\mathbf{J}} \dot{\mathbf{q}} - \mathbf{J} \mathbf{D}^{-1} \mathbf{C} \dot{\mathbf{q}}) \\ \mathbf{p} &= \mathbf{\Lambda} \mathbf{J} \mathbf{D}^{-1} \mathbf{g} \end{aligned} }\]

Contraction-Based Controller

Objective: Track desired trajectory \(\mathbf{x}_d(t)\) with guaranteed exponential convergence.

Design: Choose task force:

\[\phantomsection{ \mathbf{F} = \mathbf{\Lambda} \ddot{\mathbf{x}}_d + \boldsymbol{\mu} \dot{\mathbf{x}}_d + \mathbf{p} - \mathbf{K}_p (\mathbf{x} - \mathbf{x}_d) - \mathbf{K}_d (\dot{\mathbf{x}} - \dot{\mathbf{x}}_d) }\]

Error dynamics:

\[\phantomsection{ \ddot{\mathbf{e}} + \mathbf{\Lambda}^{-1} \mathbf{K}_d \dot{\mathbf{e}} + \mathbf{\Lambda}^{-1} \mathbf{K}_p \mathbf{e} = \mathbf{0} }\]

Contraction condition: Choose \(\mathbf{K}_p = \lambda^2 \mathbf{\Lambda}\), \(\mathbf{K}_d = 2\lambda \mathbf{\Lambda}\) to get:

\[\phantomsection{ \ddot{\mathbf{e}} + 2\lambda \dot{\mathbf{e}} + \lambda^2 \mathbf{e} = \mathbf{0} }\]

This is critically damped with contraction rate \(\lambda\).

Metric: The natural metric is \(\mathbf{M} = \mathbf{\Lambda}\) (kinetic energy).

This is feasible if the switched system is jointly contracting.

\[\phantomsection{ \begin{aligned} \min_{\mathbf{M}} \quad & \text{tr}(\mathbf{M}) \\ \text{s.t.} \quad & \mathbf{M} \succ 0 \\ & \mathbf{A}^\top \mathbf{M} + \mathbf{M} \mathbf{A} + \dot{\mathbf{M}} \preceq -2\lambda \mathbf{M} \end{aligned} }\]

where \(\langle \mathbf{C}, \mathbf{M} \rangle = \text{tr}(\mathbf{C}^\top \mathbf{M})\).
